# 📊 盘前市场报告 Skill

**功能**：每个交易日开盘前，自动生成一份覆盖全球市场、A股全面分析、行业龙头跟踪的结构化盘前报告，并发布到公开发布的知识库。

**闭环定位**：本报告是「盘前→复盘→盘前」首尾循环的起点和终点
```
复盘报告(N-1) ──→ 盘前报告(N) ──→ 交易时段 ──→ 全量扫描(后台) ──→ 复盘报告(N)
   ↑③.4引用昨日        ③.4引用昨日                          ↑引用③.4验证     ↑明日展望
                                                                               ↓
                         复盘报告(N) ──→ 盘前报告(N+1) ──→ ...
```

## 数据依赖

本 Skill 依赖以下系统 Skill 及其 CLI 工具：

| 依赖 | 用途 |
|------|------|
| **westock-data** | 行情数据（K线、板块、资金流向、ETF、热搜、日历、新股） |
| **tencent-news** | 搜索隔夜财经新闻、市场热点 |
| **ima-knowledge** | 将报告上传到公开发布的知识库 |
| **双弦投资系统-月度股池** | 读取双弦系统收盘后积累的月度共振/低吸股池，在盘前报告中引用展示 |
| **鱼身** | 读取鱼身系统昨夜扫描的量化信号（航空加油/均线回踩/箱体突破），在盘前报告中引用展示 |
| **猛兽体系** | 读取猛兽体系趋势量化扫描的Setup评分结果（领先股/回调股/断层信号），在盘前报告中引用展示 |
| **复盘报告** | 引用昨日收盘复盘报告中的全市场资金分布数据和预判验证结论，在盘前报告③.4引入"昨日复盘→今日展望"链条 |
| **量化系统(GitHub预运行)** | 双弦/鱼身/猛兽由GitHub Actions每日15:30自动预运行，结果上传至复盘报告文件夹，盘前报告通过premarket_quant.py读取 |

**量化系统层级分工**（三系统互补，嵌入四大层级）：

| 系统 | 大盘层 | 板块层 | 个股层 |
|------|--------|--------|--------|
| 🐟 鱼身 | 🌡️ 大盘温度(开关：<40偏冷暂停) | — | 🎯 三模式买点(空中加油/回踩/突破) |
| 🐅 猛兽 | 🛡️ 安全评分(刻度：三指数加权) | 📊 板块RSR排名(主线) | ⭐ Setup八维(领先/回调/断层) |
| 🔗 双弦 | 🧭 牛熊定性(快慢弦) | 🔗 行业共振验证 | 💰 月度股池(≤10元主板) |

> 信号传导：**外围(输入) → 大盘(势：开关+刻度+方向) → 板块(线：RSR主线) → 个股(点：候选→买点→强度漏斗)**。

### Step 3.5：市场阶段定性（双弦+曾星智体系）

对 8 大指数月度 K 线数据进行以下分析：

**双弦体系**（快弦 MA20 ≈ 1月MA，慢弦 MA60 ≈ 3月MA）：
- 计算每个指数的 MA60（近3月均值）
- 当前价 > MA60 且近1月>MA60 → 多头排列 (score +2)
- 当前价 < MA60 且近1月<MA60 → 空头排列 (score -2)
- 其他情况 → 纠缠阶段 (score 0)

**曾星智体系**（半年线 MA120 ≈ 6月MA）：
- 计算每个指数的 MA120（近6月均值）
- 计算 6 个月涨跌幅
- 当前价 > MA120 且半年涨 > 0 → 看多
- 当前价 < MA120 且半年跌 < 0 → 看空
- 交叉情况 → 震荡

**综合定性**：
- 多头排列指数 ≥ 6 → 🐂 牛市
- 空头排列指数 ≥ 6 → 🐻 熊市
- 多头≥4 且 空头≤2 → 偏强震荡（结构性牛市）
- 空头≥4 且 多头≤2 → 偏弱震荡（结构性熊市）
- 其他 → 宽幅震荡

同时计算各指数近5月振幅，标注高波动（>30%）、中波动（>15%）、低波动。

### Step 4：生成报告（四层级信号传导链）

报告采用「外围(输入) → 大盘(势) → 板块(线) → 个股(点)」结构，将双弦/猛兽/鱼身嵌入对应层级。可参考 `./references/report_template_v2.md` 模板骨架。生成 Markdown 包含：

🎯 **信号快照卡** — 鱼身温度 / 猛兽评分 / 双弦定性 三系统聚合 + 当日操作基调（进攻/防守/空仓）

**① 外围环境（全球输入·解释"为什么"）**
- 1.1 美股指数+个股（Step 2.1）
- 1.2 商品/汇率（原油/黄金/美元，标注对A股成本&避险传导）
- 1.3 中概/港股
- 1.4 【落点】外围→A股传导研判（驱动大盘温度/评分的外部环境）

**② 大盘定势（能不能做·三系统聚合）**
- 2.1 鱼身温度(开关) ← `premarket_fishbody.py`（大盘温度段）；偏冷则标注"暂停开仓"
- 2.2 猛兽安全评分(刻度) ← `premarket_beast.py`（安全评分段）
- 2.3 双弦牛熊定性(方向) ← Step 3.5 双弦+曾星智体系
- 2.4 综合决策：进攻/防守/空仓 + 关键指数技术位

**③ 板块定线（做什么方向）**
- 3.1 猛兽板块RSR TOP ← `premarket_beast.py`（板块RSR段）
- 3.2 双弦行业共振/弱势验证 ← `premarket_pool.py` + 弱势板块(CPO/元件等)
- 3.3 强弱板块对照（资金共振视角） ← `sector_flow.py`（板块资金流向TOP5，交叉验证板块RSR排名与资金净流向是否一致）
- 3.4 复盘报告全市场资金分布（引用昨日收盘数据）← 从复盘报告提取

**④ 个股定点（做哪只/什么价·三层漏斗）**
- 4.1 第一层·候选：双弦月度股池 ← `premarket_pool.py`
- 4.2 第二层·形态：鱼身三模式买点 ← `premarket_fishbody.py`（信号段）
- 4.3 第三层·强度：猛兽Setup八维 ← `premarket_beast.py`（领先股/回调股/断层段）
- 4.4 可执行清单/观察名单（综合三系统 + 大盘风险，含买点/止损/仓位）
- 4.5 【新增】量化信号汇总 — 前一日forward_look_scanner的强候选/关注候选，标注主升浪等级 ← `forward_look_scanner.py`
- 4.6 【新增】主升浪候选池 — 前一日forward_look_scanner扫描结果中🔥强候选+✅关注候选的整合清单，供盘前重点关注

> 📌 **复盘报告数据引用**：③.4 章从知识库「复盘报告」文件夹中读取昨日收盘复盘报告，提取以下数据嵌入③.4：
> - 双维定性分布（情绪退潮/游资情绪/主力占比等）
> - 重点标的 Top20 名单
> - 昨日预判验证结果（准确率评估）
> 若文件不存在（如首个交易日），标注"⏳ 复盘报告尚未生成"，不影响报告完整性

**⑤ 支撑信息**
- 5.1 行业龙头跟踪（28行业，异动标注）← Step 2.4
- 5.2 本周日历/新股 ← Step 2.6
- 5.3 智能提醒汇总（Step 3 触发项归并）

**⑥ 策略要点 + 重要声明**
- 利多/利空梳理、当日关注方向、操作纪律 + 免责声明

> 📌 **三系统信号归位映射**：鱼身→②.1+④.2；猛兽→②.2+③.1+④.3；双弦→②.3+③.2+④.1。调用 `premarket_*.py` 获取原始片段后，按此映射拆分嵌入对应层级（而非独立成章）。
> 📌 **复盘报告归位**：③.4（昨日复盘全市场资金分布），引用昨日复盘报告中的全市场数据和预判验证，实现「盘前→复盘→盘前」首尾循环。

## 执行规范

1. 每一步采集到数据后立即解析并暂存，不要等全部采集完再解析
2. 所有涨跌幅计算使用 `(last - prev_close) / prev_close * 100` 公式
3. 港股价格用港元单位，美股用美元单位，A股用人民币单位
4. 报告生成的日期以平台 `<current_time>` 提供的当前日期为准（沙箱 `date` 命令可能比平台慢一天，切勿直接依赖 `date` 命令推算报告日期）
5. 如果当前日期是周末（周六/周日）或国家法定节假日，提示"今日非交易日"并跳过
6. 如果数据获取失败（如API超时），标注"数据获取失败"占位，不影响整体报告
7. **预运行规则**：Step 1.5 的双弦/鱼身预运行仅在有新K线数据的交易日执行，若数据已是最新则跳过以节省时间
8. **双弦月度股池为引用展示**：若双弦系统尚未运行（如月初尚无数据），②.3(牛熊定性)/④.1(候选漏斗)章自动跳过，不影响报告完整性
9. **鱼身扫描为引用展示**：若鱼身系统尚未运行或扫描结果为0信号，对应板块自动跳过，不影响报告完整性；当大盘温度 < 40（偏冷）时鱼身全池会直接暂停扫描（不输出 JSON），属正常策略，②.1章应标注"大盘偏冷·鱼身暂停开仓信号"而非视作报错
10. **股池路径**：双弦月度股池 JSON 文件位于 `/sandbox/workspace/skills/双弦投资系统/pools/pool_YYYY-MM.json`
11. **鱼身路径**：鱼身扫描结果位于 `/sandbox/workspace/outputs/fish_body_enhanced_最新.json`
12. **猛兽路径**：猛兽扫描输出文件位于 `/sandbox/workspace/outputs/beast_scan_output.txt`；premarket_beast.py 自动读取此文件并解析生成Markdown
13. **猛兽扫描为引用展示**：若猛兽体系尚未运行（输出文件不存在或超过24小时），②.2(安全评分)/③.1(板块RSR)/④.3(领先股)章显示"⏳ 猛兽体系尚未运行当日扫描"提示，不影响报告完整性
14. **复盘报告为引用展示**：③.4(全市场资金分布)引用昨日收盘复盘报告中的数据和预判验证结论，形成「盘前→复盘→盘前」首尾闭环。若复盘报告不存在（如首个交易日），③.4章标注"⏳ 复盘报告尚未生成"占位，不影响报告完整性。数据来源为知识库「报告」→「复盘报告」文件夹内的最新报告
15. **统一过滤规则**：所有个股筛选统一使用 `filter_rules.py` 中的 `is_tradable()` 判断可交易资格。当前等级为「主板+创业板精选」，即沪深主板(60/00) + 创业板TOP50(300xxx大盘股)，永久排除科创板(688)和ST。如需切换等级，修改 `filter_rules.py` 中的 `FilterLevel.CURRENT`。
16. **创业板精选池维护**：`filter_rules.py` 中的 `CHINEXT_TOP50` 字典为创业板精选池，每季度更新一次（剔除市值跌出前80的，补入市值进入前30的）
17. **三系统数据完整性自检（防缺失）**：Step 2.8/2.9/2.10 采集后必须验证鱼身/双弦/猛兽三数据源齐备——premarket_quant.py 与 premarket_fishbody.py 输出为空或含"暂无数据"时，须**本地补跑对应系统**（双弦 run_shuangxian.py / 鱼身 fish_body_enhanced.py --pool stock_pool.txt / 猛兽 beast_screener.py），并将本地结果写入标准路径（outputs/beast_scan_output.txt、outputs/fish_body_enhanced_最新.json）。报告中④.2/②.1等章节**标注数据来源**（"GitHub 8/6收盘实采" 或 "本地兜底 160只池"），禁止静默降级为仅温度描述。鱼身数据源优先级：本地最新JSON → GitHub仓库 fish_body_latest.json（workflow每日提交）→ 本地补跑。
18. **资金行为四态引用（黑石启发）**：信号快照卡💰行引用昨日全盘量化报告（panhou_lianghua.md 一.5章节）的四态计数（抢筹/进场/控盘），标注"昨日全市场"；若报告不存在或未生成，该行省略不影响报告完整性。数据由 full_market_dualdim.py 每日扫描产出（fund_phase：抢筹=超大单占5D净流≥30%+放量 / 进场=今日净流转正+5D正 / 控盘=缩量高沉淀 / 观望）。
19. **四因子背离/共振标注（黑石启发）**：盘前报告②.4综合决策输出四因子（均线=上证vs MA5/MA20、动量=5日涨幅、情绪=情绪退潮占比、资金=抢筹+吸筹占比）及背离/共振信号（资金高+情绪低=聪明钱布局 / 资金低+情绪高=诱多 / 动量高+情绪低=无量空涨 / 动量低+资金高=底部蓄力 / 三高=多头共振）。数据源：上证25日K线（westock）+ panhou_lianghua.md 双维分布 + 资金五态。
