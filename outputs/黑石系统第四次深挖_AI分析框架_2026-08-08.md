## 一、市场风向标：四因子择时框架 ⭐⭐⭐

**核心哲学：「因子背离即机会，因子共振即趋势」**

### 四因子联动（均线/动量/情绪/资金）
**背离信号（最具分析价值）：**
| 组合 | 解读 |
|:--|:--|
| 资金高 + 情绪低 | **聪明钱逆势布局**（机构在散户恐惧时吸筹） |
| 资金低 + 情绪高 | **散户追高、主力出货**（诱多风险） |
| 动量高 + 情绪低 | **无量空涨**（动能不可持续） |
| 动量低 + 资金高 | **底部蓄力**（方向选择在即） |

**共振信号（趋势确认）：**
- 动量+情绪+资金三高 = **多头共振**（趋势加速）
- 三低 = **空头共振**（需防御）
- 指数站上双均线+三因子齐升 = **右侧确认**

### 综合因子区间定位
冰点<20 / 低迷20-40 / 中性40-60 / 活跃60-80 / **沸点>80**（蓝绿灰橙红五色）+ **区间历史胜率**（后续5日上涨概率）

### 政策匹配
情绪低+政策重磅利好 → 政策底信号；资金高+政策加码 → 增量确认
