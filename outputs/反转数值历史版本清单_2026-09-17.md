## 二、核心公式演进（最关键）

### A2 原版（0725）核心结构

```
MACD:%(归一化)  = (DIF-DEA)*2,  其中 DIF=EMA(C,12)/C*100-EMA(C,26)/C*100
X_1 = BARSLAST(CROSS(DEA,DIF))         ; 上次死叉至今周期
X_2 = ABS(LLV(MACD,X_1))               ; 该区间绿柱最深
X_3 = MACD > 2*X_2*0.618               ; 【反转阈值】反包 2×0.618 倍
X_5 = HHV(MACD,X_4)                    ; 红柱最高
X_6 = ABS(MACD) > 2*X_5*0.618          ; 反向阈值

动量五态：
  启动点 = MACD<0 AND MACD>REF(MACD,1) AND REF(MACD,1)<=REF(MACD,2)
  逼空点 = MACD>0 AND 同上拐头 AND REF(MACD,1)>0
  回落点 = MACD>0 AND 拐头向下
  杀多点 = MACD<0 AND 拐头向下
  等长点 = MACD=CON2STR(REF(MACD,1),2)     ← 原版几乎不触发
```

### A3 改进版 9 项改进

| # | 改进项 | 说明 |
|---|---|---|
| ① | **止损价/止盈价** | 新增，以最近买入/卖出信号的最低价/最高价 ±1% 为基准 |
| ② | **趋势强度过滤** | 均线斜率 <0.8% 时信号不显示，**过滤震荡市假信号** |
| ③ | **零轴分域** | 零轴上只标「回落（减仓）」，零轴下只标「杀多（观望）」——**不再打架** |
| ④ | **文字化指令** | ▲→▶买、死叉→▼卖、启动→试仓、逼空→持有、回落→减仓、杀多→观望 |
| ⑤ | **虚线→箭头** | 零下金叉 `......`→`↑买入`；零上死叉 `......`→`↓卖出` |
| ⑥ | **面积比值化** | 绝对值 → **红柱面积/绿柱面积比值**（>1 多头主导）|
| ⑦ | **等长点放宽** | 精确相等 → 近似相等（容差 0.005），**原版几乎不触发** |
| ⑧ | **▲信号加预警线** | 新增 `●底背` 紫色预警点，**底背离出现即提示，不等金叉** |
| ⑨ | **多周期红绿计数优化** | 保留原逻辑 + 增加仓位参考文字 |

### 使用规则（改进版自带）

```
▶买 / ↑买入 / 试仓  → 关注买入机会
持有 / 逼空         → 继续持股
减仓                → 减仓 1/3~1/2
↓卖出 / 观望        → 清仓或空仓
止损价              → 收盘跌破则止损
止盈价              → 触及则分批止盈
```
