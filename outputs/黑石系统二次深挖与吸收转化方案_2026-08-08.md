## 一、二次深挖：新发现的独有资产

### 1.1 因子数据库体系（核心资产）⭐

前端代码挖出**完整因子标签**（factorTag），系统按"对象×资金行为×时间"三维存储：

| 因子标签 | 含义 | 对象 |
|:--|:--|:--|
| **SUPER_CAPITAL_ENTRY / GRAB / CONTROL** | **超级资金**：进场/抢筹/控盘 | 个股 |
| SECTOR_CAPITAL_ENTRY / GRAB / CONTROL | **板块资金**：进场/抢筹/控盘 | 板块 |
| **SECTOR_ABSORPTION_1D** | **板块吸筹**（1日） | 板块 |
| CAPITAL_FLOW_RANK | 资金流排名 | 个股 |
| SECTOR_STRENGTH / STOCK_STRENGTH | 板块强度 / 个股强度 | 双对象 |
| **RESONANCE_SIGNAL / SECTOR_RESONANCE_SIGNAL** | **共振信号** | 双对象 |

> 💡 核心洞察：**"超级资金"（SUPER_CAPITAL）是独立于板块资金的维度**——很可能指超大单/机构级资金，与我们"主力主导放量"对应，但拆分更细（进场/抢筹/控盘三阶段）。

### 1.2 乾坤算法体系（付费卖点）⭐

```
qianKun体系（乾坤）：
  qianKunOne~Six（六式）——同一方法论按级别/状态分6档
```

### 1.3 选股/榜单模式
- **百大金股**（topGoldStock/ranking）：按N日资金流入占比排名（已实测：通宇通讯6.74%）

## 二、值得吸收的亮点（按价值排序）

### ⭐⭐⭐ 亮点1：资金"三阶段"状态分类（SUPER_CAPITAL三维）
**黑石做法**：把资金行为拆成 进场(ENTRY)→抢筹(GRAB)→控盘(CONTROL) 三阶段，板块/个股各一套
**我们的差距**：full_market_scan 只有单维"沉淀率+信号类型"，无阶段划分
**转化方案**：
```python
# 用我们已有数据（5D主力净流入、沉淀率、今日净流入）构造三态：
#   ENTRY(进场)  = 沉淀率>0 且 今日净流入转正（资金开始建仓）
#   GRAB(抢筹)   = 沉淀率高 且 净流入加速（5D净流入环比上升）
#   CONTROL(控盘) = 缩量高沉淀（筹码锁定，近似现有"主力控盘"）
# 输出：每只股票标记 进场/抢筹/控盘/观望 四态 → 资金行为全景
```

### ⭐⭐⭐ 亮点2：板块吸筹因子（SECTOR_ABSORPTION_1D）
**黑石做法**：板块级吸筹识别（板块内资金集中吸筹）
**转化方案**：猛兽板块RSR + 板块资金净流入/流通市值 构造"板块吸筹度"（资金集中度指标），并入③.3强弱板块对照

### ⭐⭐ 亮点3：乾坤分级思想（One~Six）
**黑石做法**：同一策略按状态分6档（qianKunOne~Six）
**转化方案**：我们已有牛熊动态参数（偏暖/震荡/危险）——升级为**策略分级矩阵**：市场状态 × 信号类型 → 仓位/持有期建议表（对齐乾坤分级思路）

### ⭐⭐ 亮点4：共振信号结构化（RESONANCE_SIGNAL）
**黑石做法**：板块×个股共振信号独立成因子
**转化方案**：我们三系统共振（猛兽/双弦/鱼身）已有——可增加"板块共振确认"：个股所在板块资金进场 + 个股技术信号 = 共振信号（落盘为因子）

### ⭐ 亮点5：百大金股榜单
**转化方案**：把现有"主力信号TOP30"升级为"主力资金TOP100榜单"（含进场/抢筹/控盘标注）——日报新板块
