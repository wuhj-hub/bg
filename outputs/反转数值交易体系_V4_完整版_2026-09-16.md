## 〇、总纲（一句话）
**反转数值 = 用「前一柱段的极值」推算「后一柱段的反转位」；反向柱能否越过它，决定趋势强弱与转折。**
- 红绿柱 = 12/26 日 EMA 的乖离；红柱越高越久 = 主力做多越坚决。
- **红柱最高值 → 算「绿柱反转数值」；绿柱最低值 → 算「红柱反转数值」**（双向）。
- **1倍 与 2倍**：2倍 = 极值×2（更宽的失效线）。**击穿2倍 = 见顶确立。**

## 一、四线系统与强弱定式

| 线 | 来源 | 用法 |
|----|------|------|
| 红柱反转数值(1倍/2倍) | **绿柱最低处** 测算 | 判"上涨能否走强" |
| 绿柱反转数值(1倍/2倍) | **红柱最高处** 测算 | 判"下跌是否见顶" |

**强弱定式（核心口诀）**
- 下跌：**绿柱不触及**反转数值 → 走势**强** → 找 3K家军**底买点**
- 上涨：**红柱越不过**反转数值 → 走势**弱** → 找 3K家军**顶卖点**
- **强势上涨的真正标志：红柱要明显大于反转数值（最好 >2倍）**；仅"刚触及"就成高点 = 弱势
- **绿柱有效击穿 2倍反转数值 = 见顶确立**（缠论3卖）

## 二、判顶三步（视频2/4/7）

```
① 顶背离：股价新高，但红柱【无法越过】反转数值 → 顶背离
② 击穿确认：随后绿柱【击穿】反转数值（股价创新低）→ 顶背离确立
③ 双顶：再算一次，反弹红柱【仍不越过】新反转数值 → 双顶确立
   ★ 击穿【2倍】反转数值 + 创新低 → 直接确立见顶，后面持续大跌
```
- **越涨越要出局**：只要红柱不越过反转数值，无论股价是否新高，顶即成立。
- **反弹受阻位**：在"击穿2倍反转数值"的那根K线处画水平线 → 未来反弹高点常受阻于此。
- **第三出局点**：**黄白线在零轴下方形成第一根死叉 K 线** → 经典大跌结构，必出。

## 三、判底（视频3）
```
下跌【击穿】反转数值  → 见顶，不考虑（继续等待）
下跌【不击穿】反转数值 → 真正具备见底特征（重点）
```
- 下跌中绿柱【多次触及但不有效击穿】→ 反复筑底 → 常引发反转。

## 四、真假背离（视频6）★
- 先看有没有突破最初的反转数值；未突破 → 处于 MACD 震荡区间。
- **真背离 = 股价走出新低，但绿柱【没有新低、也没击穿反转数值】→ 重点操作**
- 假/失败背离 = 绿柱**击穿**反转数值（此时"背离"无效，别接）。
- 钥匙：**一切背离都用反转数值衡量**（双线背离同理）。

## 五、黄白线用法（视频5）—— 震荡市买卖 ★
- **零轴下方第一次金叉**：在黄线最低处画水平线；后续**未击穿反转数值**且**黄白线向上打破该水平线** → **买点**。
- **零轴上方第一次死叉**：在黄线最高处画水平线（第一波弱、第二波强时以第二波为准）；**黄白线上穿该水平线** → **减仓点**。
- 涨跌都未明确突破反转数值 = **震荡特征**（走势扩张/扩展）。

## 六、时间预测：一波结束模型（视频8/9）★
```
① 找【第一根红柱】→ 找这波【红柱最高】→ 统计共运行 N 个周期
② 见底时间 ≈ 【N × 0.618】（辅以 N × 0.382 给区间）
   例：N=22 → 8.4 / 13.6 → 第 8~9 或 13~14 根绿柱见底
③ 用【60分钟柱状背离模型】确认、【30分钟背离模型3】精确到K线 → 多级共振确立低点
④ 配合【3根K线+均线】底部特征 → 介入
```
- **四种结构**：柱状背离型 / 黄白线背离 / 一波结束型 / 极限型（可覆盖约 80% 顶底）。
- 大背离模型：常给出"调整 ≥40 个交易日"的量级。

## 七、买点：3K加均介入法（视频10）★
```
① MACD：绿柱【触及或未触及】反转数值，且【不出现有效击穿】
② K线：形成【品字底】——最低点K线(触及/未触及反转数值且未有效击穿)为基准，
        在其【左侧K线】的最高点画水平线；
        后面出现【实体阳线向上突破该水平线】＋【股价站上 5 日均线】 → 介入点成立
止损/止盈：5日均线
```

## 八、完整交易流程（可执行）

```
① 定方向：周线红柱=顺势；绿柱=逆势（只做超跌/真背离）
② 判强弱（四线）：上涨看红柱能否越过红反转位；下跌看绿柱能否守住绿反转位
   · 出现「绿柱击穿2倍反转数值」→ 立即规避（见顶）
③ 定时间（一波结束模型）：N×0.618 估算见底/见顶窗口
④ 找买点（3K家军底）：绿柱不有效击穿 + 品字底 + 实体阳线站上左侧K线高点 + 站上MA5 → 买
⑤ 持有：止损/止盈用5日均线（或宽止损−10%）
⑥ 卖点（三档）：① 红柱越不过反转数值 ② 击穿2倍反转数值 ③ 零轴下第一根死叉K线
⑦ 风控：单票≤5%(短线)/≤15%(主仓)；同向≤5只；月胜率<30%降仓
```

## 九、通达信公式（四线 + 二倍 + 3K框架）

```
{========== 反转数值 · 完整版 ==========}
DIF:=(EMA(CLOSE,12)-EMA(CLOSE,26))/CLOSE*100;
DEA:=EMA(DIF,9);
MACD:=(DIF-DEA)*2;

{双向反转数值（窗口40，边界已修）}
红峰:=HHV(MACD,40);   深绿:=ABS(LLV(MACD,40));
绿反转1:=0.618*红峰;  绿反转2:=1.236*红峰;   {红柱峰值→绿柱反转位}
红反转1:=0.618*深绿;  红反转2:=1.236*深绿;   {绿柱最深→红柱反转位}

{强弱/顶底}
击穿2倍:=MACD < -绿反转2;     {见顶确立（缠论3卖）}
红柱弱:=MACD>0 AND MACD<红反转1;   {上涨越不过反转数值=弱}

{一波结束模型：见底K线数 ≈ 红柱段周期N × 0.618}
红段N:=BARSLAST(CROSS(DIF,DEA));      {近似：红柱段运行周期}
见底窗口:=红段N*0.618;

{3K家军·底（买）}
新低K:=LOW=LLV(LOW,20);
K0:=BARSLAST(新低K);
K0高:=REF(HIGH,K0+1);                 {左侧K线的最高点}
站线:=CLOSE>K0高;  站MA5:=CLOSE>MA(CLOSE,5);
买点:站线 AND 站MA5 AND (MACD>-绿反转1) AND NOT(击穿2倍);

{3K家军·顶（卖）}
新高K:=HIGH=HHV(HIGH,20);
M0:=BARSLAST(新高K);
M0低:=REF(LOW,M0+1);
破线:=CLOSE<M0低;  破MA5:=CLOSE<MA(CLOSE,5);
卖点:破线 AND 破MA5 AND 红柱弱;
```

> ⚠️ 视频未公开"反转数值"的精确数学式（课程称看资料/主页）。本式中 **1倍=×0.618、2倍=×1.236** 沿用你原码口径，属**推定**；待你拿到官方资料再校正。
