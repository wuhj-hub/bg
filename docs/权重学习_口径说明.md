# 仲裁权重学习 · 口径说明

**建档**：2026-10-11 ｜ 体系：信号仲裁（signal_arbiter）权重自学习闭环
**关联**：`quant_scripts/learn_weights.py`、`signal_arbiter.py`、`config/arbiter_weights.json`、`config/source_priors.json`、`quant_scripts/weight_change_review.py`

---

## 一、闭环四步

```
learn_weights.py 统计提议  →  人工确认  →  改 config/arbiter_weights.json
        ↑                                              ↓
   weight_change_review.py 到期回验  ←──────────  次日 signal_arbiter 生效
```

- **只提议、不自动改**：`learn_weights` 输出建议与结构化提案（`outputs/权重提案_{date}.json`），**权重变更必须人工确认**后再写入 `config/arbiter_weights.json`。
- **有回验**：变更记入 `logs/weight_change_ledger.csv`，到期由 `weight_change_review.py` 回验 → 保留或回滚。
- **边界夹取**：权重取值 `[-3, 3]`（`bounds`），缺失键回退 `signal_arbiter.py` 内置默认。

## 二、三类输入

| 输入 | 文件 | 说明 |
|---|---|---|
| 信号日志 | `outputs/仲裁信号日志.csv` | `signal_arbiter` 每日追加；字段 `date,code,pts,level,month,src`（`src` 用 `\|` 分隔） |
| 历史先验 | `config/source_priors.json` | 各源历史胜率（从既有回测报告抽取） |
| 当前权重 | `config/arbiter_weights.json` | 人工维护的权重基线 |

> **2026-10-11 起日志拓宽**：`ranked[:20]→[:50]`、`src[:4]→[:8]`，使猛兽/武威/反转/123-2B/RSV 等低权重源也能进日志。注意日志为**追加式**，历史行仍是旧口径，约 2 个月后旧口径才被稀释。

## 三、粒度：按「配置键」

不再按聚合标签（"猛兽""四维"），而是**逐配置键**统计，共 17 键：

`四维高置信 / 四维弱共振 / 四维否决 / 鱼身空中加油 / 猛兽Setup60 / 猛兽Setup50 / 猛兽Setup40 / 猛兽RS_D / 猛兽G点 / 双弦共振 / 乾坤A级 / 武威精选 / 反转数值 / 123/2B / RSV-launch / RSV-hold / RSV-exit`

（其中 武威精选/反转数值/123-2B/RSV-* 暂无外置配置键，仅统计、不可自动调权）

## 四、收益与超额

- **收益** = 信号日收盘 → 至今（%）
- **超额** = 收益 − 基准（默认 `sh000001` 同期）
- 超额是判据之一，避免把"大盘普涨"误当信号有效。

## 五、判据（2026-10-11）

| 条件 | 动作 |
|---|---|
| 样本 < 10 | 维持（数据不足） |
| **后验胜率 ≥ 60%** 且（超额 > 0 或缺失） | 权重 **+1** |
| **后验胜率 ≤ 40%** 且（超额 < 0 或缺失） | 权重 **−1** |
| 其余 | 维持 |

**置信标注**（Wilson 95% 区间）：正向时下限 ≥ 0.45、或负向时上限 ≤ 0.55 → 记「高」；否则记「小样本」。

> 判定用「**后验**胜率」而非观测胜率（见第六节），以防止小样本过拟合。

## 六、先验与收缩（P1，2026-10-11）

各源历史胜率作为 **Beta 先验**，与日志观测做收缩：

```
后验胜率 = (观测赢数 + c × 先验胜率) / (样本数 + c)
c = min(先验样本数, shrink_cap)        # shrink_cap 默认 20
```

先验取自仓库既有回测报告（**跨口径/持有期不一，仅作先验、非精确比较**）：

| 信号源 | 先验胜率 | 样本 | 来源 |
|---|---|---|---|
| 鱼身空中加油 | 47.7% | 4302 | 回测卡·持5日（FAIL） |
| 鱼身均线回踩 | 47.1% | 8726 | 回测卡·持5日（FAIL） |
| 鱼身箱体突破 | 47.0% | 2931 | 回测卡·持5日（FAIL） |
| 猛兽Setup（技术代理） | 53.3% | 75 | 回测卡·持4周 |
| 反转数值 | 51.1% | 1379 | 全体系回测全景回顾·周线 |
| 123/2B | 49.2% | 323 | 全体系回测全景回顾·全主板2B |
| 武威精选 | 65.8% | 336 | 全体系回测全景回顾·武威G1∩反转 |

（四维/双弦/乾坤/RSV 无历史回测 → 无先验，纯日志驱动）

**效果**：样本少时向先验靠拢（如 鱼身空中加油 观测 28% → 后验 35%），样本增多后由日志主导。

## 七、何时该动权重（操作建议）

1. **只动「高置信」** 且信号逻辑未变的项；
2. 一轮最多调 1~2 个键，便于归因；
3. 改后**走 `weight_change_review.py` 到期回验**，不达标即回滚；
4. **先验/日志冲突时以信号逻辑为准**——统计只回答"历史上灵不灵"，不回答"为什么"；
5. 阈值（60%/40%、shrink_cap）若调整，同步升版本本文。

## 八、已知局限

- **日志覆盖**：曾因 `TOP20 + src[:4]` 漏掉猛兽等（2026-10-11 已修，但需时间积累）；
- **追加式混存**：新旧口径并存约 2 个月；
- **样本量**：日志累积慢（约 11 行/交易日），源级样本仍偏少；
- **先验跨口径**：来自不同回测（持有期/样本池/口径不一），只宜作先验；
- **存活/选择偏差**：信号多来自当日强势股，可能高估。

## 九、维护约定

- 先验表（`config/source_priors.json`）：每 **1~2 个季度**用新回测复核一次；
- 本文：口径变更（阈值/收缩参数/粒度）时**升版本**，旧版改名 `_vN` 保留；
- 月度运行：`python3 quant_scripts/learn_weights.py --emit-proposals`。
