## 一、定位与读者

- **读者画像**：有一定交易经验的 A 股投资者、量化/自动化爱好者
- **核心卖点**：⭐ **公开最细颗粒度**——每个信号都给**明确阈值**、每个结论都给**回测证据**（这正是本体系区别于"嘴炮号"的地方）
- **叙事主线**：一个散户，用**免费数据 + 免费算力 + 免费大模型**，搭出一套**全自动的多系统量化流水线**
- **基调**：务实、不吹收益、强调"体系与纪律"，主动交代**边界与教训**

## 二、篇章结构（12 篇）

### 第 0 篇 · 开篇：我为什么把炒股做成了"流水线"
- **核心问题**：散户为什么总是"看对做错"？——因为**没有体系、没有纪律、没有闭环**
- **要点**：全景图（一张图看懂 14 条自动任务）｜盘前→盘中→盘后一天的样子｜本文的连载计划
- **素材**：今日盘前报告结构（①外围→②大盘→③板块→④个股→⑤策略）、workflow 清单

### 第 1 篇 · 数据地基：不花一分钱的数据与算力
- **核心问题**：没预算能不能做量化？
- **要点**：免费数据源三件套（腾讯 westock / 东财 push2 / 同花顺长历史）各自能取什么｜GitHub Actions 免费跑批 + cron-job.org 精确触发｜**踩坑：免费 GitHub cron 会降频/丢单，必须外部触发**
- **素材**：`data_guard.py`（数据源探针）、外部触发体系文档

### 第 2 篇 · 方向层：曾星智「力量投资」
- **核心问题**：先定方向，再谈个股
- **要点**：9 大指数**长期力量 / 短期力量**双维度（长期熊 + 短期多 = 可做短线）｜月线力量（MA6/MA12）｜**入牛时点的"板块先入牛 vs 个股先入牛"时点差**
- **素材**：`xzz_force.py`、`scan_inbull.py`、《板块个股入牛时点》技能

### 第 3 篇 · 强度层：猛兽体系 v3.0（三层漏斗）
- **核心问题**：同一方向里，选哪只最"强"？
- **要点**：大盘安全→板块 RSR→个股信号三层漏斗｜十维 Setup 评分（VAD/OVS/SSV/RSL/RS_D…）｜双模式（堆量/欧马）｜**回测：Setup≥55 在部分环境为负 → 用环境表开关**
- **素材**：`beast_screener.py`、`beast_pool.yml`

### 第 4 篇 · 共振层：双弦体系
- **核心问题**：怎么把"方向"和"强度"合成一个信号？
- **要点**：快弦（日）/慢弦（周）共振｜**低价股月池（≤10 元）的分层管理**（核心≥65 / 观察 50-65 / 低吸独立）
- **素材**：`run_shuangxian.py`、`dual_pool_sync.py`

### 第 5 篇 · 买点层：三种买点，各管一段行情
- **核心问题**：什么时候下手？
- **要点**：鱼身（MACD 空中加油 / 均线回踩 / 箱体突破）｜武威 G1（双阴缩量回调，月线级）｜才哥「涨停王者倍量柱」（T+3 确认）
- **亮点**：⭐**「涨停后顶格筹码峰不动（锁仓）」实测无正收益，反而"筹码换手活跃"的更好**——反直觉，有话题性
- **素材**：`fish_body_enhanced.py`、`wuwei_scan_month.py`、`wangzhe_track.py`

### 第 6 篇 · 风控层：执行卡（把"仓位"算清楚）
- **核心问题**：为什么很多人方向对还是亏？
- **要点**：三级门禁（月线+周线方向 → 放行/试仓/拦截）｜**资金预算卡**（2×ATR 止损 / 盈亏比≥2 / 单票≤30%）｜**分批 B1/B2/B3**｜"盈亏比不足"≠不能买，是"赔率不够"
- **素材**：`execution_card.py`、今日执行卡输出（博通集成/新朋股份等案例）

### 第 7 篇 · 情绪层：连板梯队与"板块先锋"
- **核心问题**：情绪怎么量化？
- **要点**：情绪温度（涨停家数×连板高度×占比）｜退潮预警｜⭐**独家发现：首板次日晋级率 15.5%，但"板块内最早封板（先锋）"达 20.2%，而"热门板块跟风股"低至 7.9%**——"抢热门"是错的，"抢先锋"才对
- **素材**：`hot_emotion.py`、`xzz_shortlist.py`、`zj_filter.py`

### 第 8 篇 · 智能化：给体系装上"嘴"（免费 GLM）
- **核心问题**：规则化报告太"硬"，缺人话怎么办？
- **要点**：智谱 GLM-4-Flash **永久免费**接入｜盘前/盘后自动生成"外围→A股传导研判"｜**成本 0，失败不阻断主流程**
- **素材**：`llm_glm.py`、`glm_brief.py`、今日报告里的 GLM 节

### 第 9 篇 · 验证：怎么不被自己的回测骗
- **核心问题**：回测好看=实盘能赚？
- **要点**：⭐**未来函数陷阱**（ZIG 指标胜率 68%→54% 的真实案例）｜样本与基准对照｜分环境检验（20 年、Newey-West）｜**"日均超额"受右尾影响，中位约为 1/3**
- **素材**：多份回测报告、环境切换决策表

### 第 10 篇 · 闭环：一天是怎么运转的
- **核心问题**：体系如何"自我运转"？
- **要点**：盘前报告 → 盘中监控 → 盘后扫描 → 复盘报告 → **judgment 闭环（盘前预判被次日复盘验证）**｜产物全部沉淀知识库｜异常自动告警
- **素材**：`quant_report.yml`、`premarket_report.yml`、知识库三类报告

### 第 11 篇 · 边界与教训（收尾）
- **核心问题**：这套体系做不到什么？
- **要点**：🐻 **熊市里多数信号为负**（环境表显示多系统在特定环境失效）｜免费数据的限流/丢数｜回测的幸存者偏差｜**踩坑集**（并发写文件致 workflow 空、日志假绿、日期时区…）
- **价值**：诚实 = 信任

## 三、写作与发布建议

1. **顺序**：先 0（勾人）→ 2/3（核心方法）→ 6/7（干货反差）→ 9/11（深度与诚实），不必严格按层
2. **每篇结构**：痛点 → 方法（给阈值）→ 回测证据 → 实操示例 → 边界
3. **钩子**：优先用**反直觉数据**（晋级率、筹码锁仓、ZIG 未来函数）
4. **连载节奏**：每周 2 篇，第 0 篇先发"全景图"引流
5. **合规**：全程强调"不构成投资建议"，标的只作方法演示
