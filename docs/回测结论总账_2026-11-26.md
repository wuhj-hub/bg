# 回测结论总账（Decision Ledger）

> 版本：v1 ｜ 2026-11-26 ｜ 维护：体系自检的一部分，不是一次性文档
> 用途：**任何「要不要再测一次」的问题，先查这里。**
> 数字以原始报告为准，本文件是「结论 + 索引 + 禁止重复」三合一。发现与原始报告冲突时，改本文件并注明出处。

## 0. 使用约定

1. 三态标记：**✅ 已验证有效** / **❌ 已否决** / **⏳ 证据不足**
2. 每条必须带：口径、样本、结论、出处（脚本或报告）。
3. **铁律：已否决的假设，除「新数据窗口 / 新市场状态 / 新口径」三种情况外不得重测。** 重测前先在本文登记「重测理由」，否则视为重复烧算力。
4. 每条只写「可执行结论」，不写过程。

## 一、元规律（比单条结论更值钱）

这 8 条是 20+ 次独立回测反复撞出来的，**所有新模型上线前先对照一遍**。

| # | 元规律 | 证据 |
|---|---|---|
| M1 | **追高类信号系统性负期望**：涨停追高、放量创新高、形态突破追买，9 个独立回测结论一致 | 见 §3 全部条目 |
| M2 | **隔夜跳空吃掉 T+1 溢价**：同一信号「T 收盘买」与「T+1 开盘买」可差 1.5~2pp，只有开盘口径才是可执行口径 | 涨停 T+1 收盘买 +1.21% → 开盘买 −0.35%；曾星智 G5 收盘 +0.60% → 开盘 −0.53% |
| M3 | **不做环境分层 = 结论无效**：同一形态牛市 +2.69pp、弱市 −16pp | 5K 强度、百日前高放量板、王者突破均复现 |
| M4 | **形态强度与次日收益不单调**（日内尤其）：最强形态往往是最差的买入点 | 开盘八法 ρ=+0.144(p=0.73)，三高盘 T+1 −0.039% |
| M5 | **前视偏差是本体系第一大陷阱**：凡用「未来形态完成」定义买点窗口，结论必然虚高 | 峰峦叠翠 20日 +10.6% → 可交易口径 +1.11%（≈基准） |
| M6 | **显著性必须按日聚类**：同日全市场同步涨跌，i.i.d. 的 t 严重虚高 | 开盘八法 ρ=+0.801(p=0.017) → 按日 −0.036(p=0.93) |
| M7 | **赔率高 ≠ 期望正**：最大浮盈 +16~19%、胜率 50%，但收益中位为负 → 彩票型 | 涨停、5K、王者突破、主升浪四信号 |
| M8 | **确认条件越多越差**：叠加「金叉/放量/新高」只会减少样本、不提高期望 | 月线倍量柱：裸 +11.37% → 加金叉无改善 → 加 EMA 最差 |

**推论**：本体系真正的 alpha 只可能来自「**低位 + 缩量 + 回踩确认**」这一侧，不在「高位 + 放量 + 突破」这一侧。

## 五、口径与工程铁律（比模型更容易出错的地方）

1. **买入口径**：信号日收盘确认 → **T+1 开盘价**买入。任何用信号日收盘价算出的收益都必须标注为「理论值」。
2. **可买性**：信号日涨幅 ≥9%（涨停）或次日一字板，必须剔除或标注「买不到」。
3. **退市/停牌**：`rows[-1].date` 距今 >15 天视为无效样本（主板清单含 ~7.6% 已退市代码）。
4. **显著性**：并列「i.i.d. t」与「按日聚类 t」；两者符号不一致时以聚类为准。
5. **环境分层**：至少分 牛/震荡/弱 三档（`regime_history.csv` 已有 531 交易日）。
6. **持有期**：报告 5/10/20/60 日，不报「最大浮盈」单独作为收益。
7. **成本**：双边 12~16bp；日内策略必须扣除。
8. **数据源**：westock 单次 250 根上限、批量 100/批最可靠；腾讯 fqkline 可取 800 根但会 WAF 限流；同花顺 period 01=日/11=周/21=月。
9. **计价时点**：同一信号「入池日收盘」与「次日开盘」两个口径可差 10~20pp（双弦低吸 35% vs 52.4%）。报告里必须写明用的哪个，跨报告对比前先对齐。
10. **自带收益列不可信**：任何 CSV 里已算好的 r5/r10/r20 都要先核对计价起点（`jingjia_signals` 的 R 列即为反例）。
9. **复权**：建等权指数用后复权时须屏蔽非正价 + winsorize（高分红股会出现负价）。
