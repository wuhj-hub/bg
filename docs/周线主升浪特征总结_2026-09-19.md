# 周线主升浪特征 · 全网总结与体系对照

> 整理时间：2026-09-19
> 目的：汇总多个来源对「周线主升浪」的描述，交叉对照，并标注哪些已被我们回测验证、哪些是缺口
> 数据基准：`wangzhe_signals.csv`(29,732) + 841只主板周线回测(2015-2026)

---

## 一、核心结论（先说重点）

多个来源对"周线主升浪"的描述**高度一致**，集中在**四条**：

```
① 均线：5/10/20周均线从长期粘合缠绕 → 向上发散、多头排列
② 量能：突破当周量 > 前5周均量 1.5 倍（但不超过 5 倍）
③ 形态：横盘 8-12 周、振幅<20% 的箱体，放量长阳突破且站稳 3% 以上
④ 回调：缩量回踩 5周/10周均线不破 = 二次买点
```

**其中 ② 已与我们的回测交叉验证通过**（详见第四节）。

---

## 二、多来源特征清单

### ① 均线系统（最核心）

| 来源 | 描述 |
|---|---|
| 易有料 | "5周/10周/20周三条均线，从长期粘合缠绕，彻底转为向上发散，形成标准多头排列"；**"均线长期粘合=主力洗盘痕迹"** |
| 股海网 | 短期(5/10周)、中期(20/30周)均线在突破前**高度密集缠绕**，随后放量向上发散；**双金叉验证**：5周上穿10周 + 60周同步金叉120周 |
| PDF(周线月线) | **"周K线生命线是MA20，主升浪看的是MA5"**；主升浪前洗盘 = MA5与MA10短暂碰撞，**依托MA20扶摇直上** |
| 头条 | 5/10/20周**依次向上发散**；只需均线不拐头，趋势不反转 |

**共识**：**粘合（洗盘）→ 发散（启动）** 是主升浪的均线本质。

### ② 量能

| 来源 | 阈值 |
|---|---|
| 易有料 | 突破当周量 **> 前5周均量 1.5 倍** |
| 股海网 | 突破量需达前一周 **2-3 倍，但不超过 5 倍（避免诱多）** |
| 头条 | "连续 3-5 周温和放量形成**量堆**"；突破量需达平台期均量 1.5 倍左右 |
| 股海网 | **"上涨量不够，全是假突破；下跌量不缩，都是真出货"** |

**共识**：**温和放量（1.5~5倍）**，**拒绝巨量**。

### ③ K线形态

| 来源 | 描述 |
|---|---|
| 头条/易有料 | 横盘 **8-12 周**、振幅 **<20%** 的箱体；放量长阳突破上沿，**收盘站稳突破位 3% 以上** |
| 易有料 | 当周收**实体饱满**中阳/大阳，**无超长上影**（长上影/小阳碎阳 = 资金犹豫）|
| PDF | 主升浪一般是 **3-5 根大阳线**（周涨幅 **≥10%**），中途可夹杂 1-2 根十字星；末段冲顶阳线常见 **20-30%** |

### ④ 回调质量

| 来源 | 描述 |
|---|---|
| 头条 | 强势股回调 **3-4 周**，不跌破 5周/10周均线，短暂跌破也迅速收回 |
| 易有料 | 回调期周K多为十字星/小阴小阳/带长下影 = **"有分寸的洗盘"** |
| 股海网 | 突破后**缩量回踩 5周或10周均线不破 = 二次买点** |

### ⑤ 技术指标

| 指标 | 条件 |
|---|---|
| 周线 MACD | **0 轴附近金叉**，红柱持续放大；0 轴以上第二次金叉更强 |
| KDJ | 主升浪中**反复高位钝化**（与常规超买用法相反，钝化=强势）|
| 趋势线 | 突破周线级下降趋势线或横盘箱体 |

### ⑥ 筹码 / 换手

- 底部**单峰密集**，突破后**上方无套牢盘**
- 换手率 **2-3% 最佳**，超过 10% 应谨慎

### ⑦ ⚠️ 风险与陷阱（重要）

| 陷阱 | 识别 |
|---|---|
| **假突破** | 突破后**连续两周收盘重回阻力线下** + 量能萎缩 |
| **高位诱多** | 累计涨幅 **>50%** 后单周换手率 **>30%** |
| **均线压制** | **10周线向下时，任何反弹均为卖点** |
| 巨量出货 | "陡然放大倍数过多不能走出趋势，**一柱擎天或昙花一现**"（简素）|

## 三、与体系的对照

| 特征 | 体系现状 | 缺口 |
|---|---|---|
| 均线粘合→发散 | 有"极致收缩"说法（如云南锗业）但**未量化** | ⚠️ **缺量化指标** |
| 温和放量 1.5~5 倍 | ✅ **已回测验证**（2-3倍最优，≥5倍转负）| 已具备 |
| 箱体突破 + 站稳 3% | 无 | ⚠️ **缺** |
| 缩量回踩 5/10 周线 | 无 | ⚠️ **缺** |
| 周线 MACD 0 轴金叉 | 有 `monthly_macd`（月线）| ⚠️ 周线级缺 |
| 上涨放量/下跌缩量 | ✅ 王者倍量柱 A3/A5 已含 | 已具备 |
| 高位换手 >30% 警示 | 无 | ⚠️ 缺 |

## 四、⭐ 交叉验证：我们回测与"经典说法"的对撞

### ✅ 验证通过的一条

| 说法 | 我们的数据（841只主板，2015-2026）|
|---|---|
| "放量 1.5-5 倍，**不超过 5 倍**" | **2~3 倍最优（8周超额 +2.41%）**；3~4 倍 +2.27%；4~5 倍 +1.46%；**≥10 倍 −1.95%** |

→ **多个来源的"温和放量"警示，被我们的独立回测证实**。

### ❌ 被证伪的两条

| 说法 | 我们的数据 |
|---|---|
| "一周量超前周 **4-5 倍**可放心买入"（周线黑马三要素）| 4~5 倍仅 +1.46%（< 2-3 倍的 +2.41%）|
| "放量突破 **30 周线**"（笑傲牛熊公式原样）| 4/5/8周超额 **−0.11% / −0.17% / −0.53%** ❌ |
| "5 周卖出法"（黑马多为5周）| 5周 +1.23% < 8周 +2.08% ❌ |

**原因推测**：这些经典源自**美股**（放量=机构建仓），而 A 股主板放量常是**散户涌入/情绪高潮** → 巨量反而是出货。

### ✅ 但有一条被强烈确认

| 说法 | 我们的数据 |
|---|---|
| "底部"是前提 | **非底部 + 放量 2~3 倍 → 8周超额 −1.64%；非底部 + 放量≥5倍 → −2.67%** |

→ 同样都强调"底部"（"洗盘完毕""抛压耗尽"），**我们的数据完全支持**。

## 五、可吸收的增量（3 项）

### 1. 均线粘合度指标 ⭐（最值得做）

把"5/10/20 周均线的收敛程度"量化，例如：

```
粘合度 = (max(MA5,MA10,MA20) − min(MA5,MA10,MA20)) / MA20
粘合信号：连续 N 周 粘合度 < 阈值（如 5%）
```

**用途**：作为"变盘前夜"预警（我们已有"极致收缩"的说法，但缺统一口径）。

### 2. 箱体突破 + 站稳确认

```
箱体：过去 8-12 周，振幅 = (max(H)−min(L))/min(L) < 20%
突破：当周收盘 > 箱体上沿 × 1.03
```

### 3. 缩量回踩二次买点

```
条件：突破后回调 ≤4 周，最低价不破 10 周均线，回调期均量 < 突破周量 × 0.6
```

## 六、与我们"底部周线放量"发现的整合建议

| 维度 | 已确认有效的组合 |
|---|---|
| **位置** | 距 52 周高回撤 **>40%**（必要条件，非此则负超额）|
| **量能** | 本周量 / 上周量 ∈ **[2, 3.5)** |
| **持有** | **8 周最优**（+2.08%），12 周 +2.84% |
| **环境** | 需加过滤（弱市年 2017/2018/2023/2026 失效）|
| 可叠加 | 均线粘合度（待验证）+ 板块共振（≥3只同行业）|
