# 📱 手机端 workbuddy 量化体系操作手册

> 版本: v1.0 | 更新: 2026-08-15
> 原则: 手机端 = **对话触发 + 被动接收 + 轻量查看**（重计算全在 GitHub Actions / 云端）

---

## 〇、手机端能做什么（能力边界）

| 操作 | 方式 | 说明 |
|------|------|------|
| ✅ 每日报告接收 | PushPlus 推送 | 盘前/复盘/股池/自检自动推微信 |
| ✅ 对话触发报告 | workbuddy 对话 | 说"出盘前报告"/"出复盘报告" |
| ✅ 对话查个股/股池 | workbuddy 对话 | 说"分析京东方"/"看才哥股池" |
| ✅ 知识库查看 | ima App | 历史报告/复盘/盘后量化 |
| ✅ 手动触发扫描 | 手机浏览器 GitHub | Actions → workflow_dispatch |
| ⚠️ 凭证更新 | 需电脑或对话 | 重新生成后告知 AI 更新 |

---

## 一、日常被动接收（无需操作）

PushPlus 已推送至微信，每天固定收到：

| 时间 | 推送 | 内容 |
|------|------|------|
| 08:00-09:00 | 📊 盘前报告 | 基调/仓位/板块/个股清单 |
| 16:30-17:00 | 📊 复盘报告 | 预判验证/明日展望 |
| 15:30 后 | 🏆 股池信号 | 才哥/一统天下/乾坤等 |
| 09:30 | 🛡️ guard 自检 | 体系健康（异常才推） |
| 盘中 | ⚡ 异动监控 | 持仓/候选突破 |

> 📌 收到推送 = 体系正常。连续 2 天没收到盘前/复盘推送 → 见「六、故障排查」。

## 二、早盘出盘前报告（08:00-09:00，可选）

```
打开 workbuddy → 输入：
  "出盘前报告"
```

**等待约 2-3 分钟**（数据采集+生成）→ 推送自动到微信 + 知识库可查。
可附加要求："重点看半导体" / "仓位建议多少" 等。

## 三、收盘出复盘报告（16:30-17:00，可选）

```
输入："出复盘报告"
```

> 💡 若 17:00 后还未收到自动复盘推送，手动触发此命令（workflow 自动版可能因数据链路延迟）。

## 四、盘中/盘后查询（随时）

| 你想问 | 输入 |
|--------|------|
| 个股分析 | "分析京东方、华能蒙电" |
| 股池状态 | "看才哥战法股池" / "一统天下建仓区有哪些" |
| 持仓风控 | "我的持仓离场信号" |
| 大盘温度 | "今天三系统温度" |
| 做T建议 | "华能蒙电今日做T点位"（zuot_kuangren） |
| 板块主线 | "今天哪些板块强" |

## 五、手动触发 GitHub 全盘扫描（手机浏览器）

当 workflow 自动运行失败或想补跑：

```
1. 手机浏览器打开: github.com/wuhj-hub/bg/actions
2. 选「全盘量化扫描」→ Run workflow → 绿色按钮
3. 约 3-6 小时跑完，结果自动推知识库+微信
```

（需要 GitHub 账号登录；或直接在 workbuddy 里说"手动触发全盘扫描"由 AI 调 API 触发）

## 六、故障排查（手机端可完成）

| 现象 | 处理 |
|------|------|
| 没收到盘前/复盘推送 | 对话输入"出盘前报告"/"出复盘报告"手动触发；或"查 GitHub 全盘扫描状态" |
| 报告内容缺量化数据 | 对话"检查 quant_results_latest 是否最新" |
| 提示凭证失效 | 告知 AI："IMA 凭证失效"，然后按提示到 ima 重新生成（ClientID/APIKey 发给我） |
| 想知道体系是否健康 | 对话"guard 自检结果"（每日 09:30 自动跑，异常会推送） |
| 股池没信号 | 正常（信号低频），可看历史："最近一周才哥股池信号" |

```text
出盘前报告 / 出复盘报告

分析 京东方A 华能蒙电 灵康药业
我的持仓风控状态
今天大盘三系统温度
华能蒙电做T点位

guard自检结果
更新IMA凭证（配好凭证后说"凭证已更新，同步三个仓库"）
```

## 八、手机端不建议做的事

- ❌ 跑全市场扫描（3000只，耗时 8-15 分钟，留给 GitHub Actions）
- ❌ 长回测（留给电脑/后台）
- ❌ 大规模知识库整理（提示词受限）
