# 曾星智「短线备选池·晋级率跟踪」· 二期落地报告（2026-09-21）

> 来源：曾星智《利用反弹行情做好短线》(2026-09-21) 吸收的二期任务
> 脚本：`quant_scripts/xzz_shortlist.py`（本地日线自算涨停+连板）
> 样本：主板 3018 只 × 156 交易日（**2026-01-14 ~ 2026-09-18**）

---

## 一、方法

1. 自算涨停（主板，涨幅 9.8%~10.5%）与**连板数 lbc**
2. 每日"短线备选池" = 当日涨停股
3. 跟踪**次日晋级**（次日是否继续涨停）
4. 统计：整体 / 按连板数分层 / 分阶段

> 曾星智排除规则（无明确热点概念归属的"华字辈"不纳入）需板块归属数据，二期先用全量涨停做基准；概念过滤待接 `sector_component_em.json`。

---

## 二、结果

### 2.1 涨停次日晋级率（按连板数分层）

| 层级 | 样本 | 次日晋级率 |
|---|---|---|
| 全部涨停 | 9322 | 18.5% |
| **首板（1板）** | 7614 | **15.5%** |
| 2板 | 1168 | **27.6%** |
| 3板 | 317 | **42.0%** |
| 4板及以上 | 223 | 41.3% |

→ **强者恒强**：连板高度越高，次日晋级率越高（3板 42% 是首板 15.5% 的 **2.7 倍**）。

### 2.2 首板晋级率 · 分阶段（每 ~20 交易日）

| 区间 | 样本 | 首板晋级率 |
|---|---|---|
| 01-14~03-05 | 555 | 18.2% |
| 03-06~04-02 | 738 | 14.6% |
| 04-03~05-06 | 996 | 14.7% |
| 05-07~06-03 | 1123 | 14.5% |
| 06-04~07-02 | 1430 | 16.2% |
| 07-03~07-30 | 984 | 13.4% |
| 07-31~08-27 | 1072 | 16.7% |
| 08-28~09-18 | 716 | 16.8% |

→ 首板晋级率长期稳定在 **13%~18%**，无显著升降。

---

## 三、结论

1. **首板晋级率仅 15.5%** —— 纯"押注首板次日涨停"胜率低，必须叠加筛选（概念归属/龙头地位/量能），与曾星智"只做有热点概念归属标的"一致。
2. **连板高度是强信号**：2板 27.6%、3板 42.0% → 打板体系里"接力高板"胜率显著高于"抢首板"。
3. 晋级率可作为**情绪温度计的补充刻度**：当首板晋级率明显高于 18%（如 >22%）→ 题材接力活跃；低于 13% → 情绪退潮。
