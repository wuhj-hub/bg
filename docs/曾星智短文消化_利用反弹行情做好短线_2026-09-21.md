## 一、原文核心（六点）

1. **9 大指数"长期力量"全部向下** → 大方向认定 **"熊市"**
   （上证、深证、上50、沪深300、中小100、创业板、科创50、北证50、中证500）
2. **"短期力量"向上 = 短线反弹成立**：9/15 起领涨，短期力量保持向上并带动更多指数同步 → **短线适合做多**
3. 结构结论：**长期熊市 + 短期反弹（领涨=科创50）**
4. 今日热点：一级行业（船舶/医药/房地产/日化/医疗保健/旅游/农林牧渔）；二级板块**全部属医药**（免疫治疗/CXO/创新药/减肥药/维生素/肝炎/仿制药）；跟踪概念=**医药、大金融、房地产**
5. **热点概念龙头拆解**：最高 5 板华瓷股份、4 板世联行/内蒙新华；备选晋级：南华生物(3板)、华纺股份(3板)、绿地控股/百通能源/华金资本/大亚圣象/新华文轩(2板)
6. **龙头排除规则**：华瓷股份、内蒙新华因属"华字辈"、**无热点概念归属**被忽略 → 只做**有明确热点概念归属**的标的
