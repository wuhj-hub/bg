## 一、西湖体系全貌（从文章反推的方法论架构）

西湖体系是一条**「大盘择时 → 主流板块 → 领头羊个股 → 买点/止损」的欧奈尔派（CANSLIM/股票魔法师）量化链**，全部指标以通达信公式实现。

```
第一层 大盘（M）      250日线占比 / 50日线占比 / 强势股占比 / 第二阶段占比 / NH-NL 下雨图
第二层 主流板块        强势板块 Top10 分布图 + 板块动量（个股RPS）+ 创新高能力
第三层 个股强度        RPS50/120/250（>85/87/90）+ 第二阶段属性 + 接近一年新高90% + 港资持股
第四层 买点/止损       RPS翻红后回踩均线 / 回踩50日线 / 三重滤网 / 7%硬止损
```

**核心三块基石**：① **RPS 相对强度**（"RPS高于一切"）；② **第二阶段属性**（股价>50日线 + 均线多头排列）；③ **50日线**（二阶段生命线、中线止损线，≈10周线）。

## 二、可吸收增量清单（按优先级）

### 🥇 P1 — 高价值、我方明确缺口、可直接落地

#### P1-1. 标准 RPS 体系（RPS50/120/250）【最核心】
- **西湖原文**：`RPS = EXTDATA_USER(n,0)/10`；常用阈值 **85 / 87 / 90**；多周期**并集 OR 扩池、交集 AND 严选**；"两条RPS翻红"（120/250/50 任两条>90）为强势过滤。
- **我方现状**：体系尚未落地标准 RPS（50/120/250）三周期口径，CANSLIM 的 L 要素因此缺一半。
- **落地建议**：新建 `quant_scripts/rps.py` —— 对全主板按 N 日涨幅排序计算百分位（RPS=(1−排名/总数)×100），输出 `rps_latest.json`（含 rps50/rps120/rps250）；供选股、打分、信号仲裁复用。

#### P1-2. RPS 翻红后回踩均线（低吸买点信号）
- **西湖公式**：
  ```
  FH := (RPS120>90 AND RPS250>90) OR (RPS250>90 AND RPS50>90) OR (RPS120>90 AND RPS50>90);
  HC := |C/MA(C,10)-1|*100<=N OR ...MA20... OR ...MA30... OR ...MA50...;
  XG := FH AND HC;     {N默认2，可严设为1}
  ```
- **我方现状**：鱼身/强势体系有"均线回踩"，但**未经 RPS 强度过滤**——低吸信号质量可再筛一层。
- **落地建议**：新增信号源「RPS翻红+回踩均线」，并入信号仲裁；回踩偏离度 N=2（±2%）可配。

#### P1-3. 市场宽度三指标：强势股占比 + 第二阶段占比 + 50日线占比
- **西湖原文**（大盘量化系统，全市场 INSUM 统计）：
  - 强势股占比 `QSG%` = 满足 `CLOSE/HHV(HIGH,250)>0.9` 的家数 / 沪深A股；参考线 **6 / 20**
  - 第二阶段占比 `EJD%` = 满足第二阶段公式的家数 / 沪深A股
  - 50日线占比（《以交易为生》）：**极端值 >75% 或 <25% 后反弹 = 中期趋势转折点**
  - 250日线（年线）占比（牛熊分界）
- **我方现状**：`market_width.py` 有"上涨占比/当日强势(≥5%)/涨停数"，**缺二阶段占比、强势股(接近一年新高)占比、50日线占比三条**。
- **落地建议**：扩展 `market_width.py` 增加 `strong_ratio`（一年新高90%）、`stage2_ratio`、`ma50_ratio`（及 `ma5_ratio`），融入宽度分与预警；加 **75%/25% 双预警线**。

#### P1-4. NH-NL 指标（新高−新低家数差）
- **西湖原文**：`NH-NL = 创一年新高家数 − 创一年新低家数`；0轴上红=强势/中期信号，0轴下绿=弱势；**指数新高而NH-NL转头向下=背离**；峰位≤+100、谷底≥−100 提示主要反转；横盘时NH-NL上升=买进信号。
- **我方现状**：缺（`yearline_breadth.py` 统计的是"站上年线比例"，与之互补但不相同）。
- **落地建议**：新建 `quant_scripts/nh_nl.py`（全A一年新高/新低家数 → `nh_nl_latest.json`），接入 `market_regime` 与盘前报告"下雨图"式呈现。

### 🥈 P2 — 中价值、已有骨架待补强

#### P2-1. 第二阶段属性个股判定（股票魔法师/温斯坦公式）
- **西湖公式**：
  ```
  CLOSE>MA(C,50) AND MA(C,50)>MA(C,150) AND MA(C,150)>MA(C,200)
  AND EVERY(MA(C,200)>REF(MA(C,200),1), N)      {N默认20}
  AND CLOSE/LLV(CLOSE,200)>1.3 AND CLOSE/HHV(CLOSE,200)>T   {T默认0.75}
  ```
- **我方现状**：曾在《停更真相》消化中识别为缺口（拟建 `stage2_check.py`，温斯坦6条件），尚未落地。
- **落地建议**：直接用此公式实现 `stage2_check.py`，为猛兽/鱼身候选池打 **Stage2 标识**，并作为 P2-1 与 P1-3 的共同基础。

#### P2-2. 周线 MACD ≥ 0 大周期过滤（三重滤网第一层）
- **西湖原文**：周线 `MACD1 = 2*(EMA(C,12)-EMA(C,26)-EMA(9)) >= 0`；强势/第二阶段股池中约 **70%→86%** 处于周线上升期（反向验证趋势模式有效）。
- **我方现状**：`xihu-report`（三重滤网扫描）已用"周线MACD>0轴"。
- **落地建议**：**校对口径**——西湖用 MACD **柱线(DIF-DEA)≥0**，我方若用 DIF>0 需统一；并把"70%→86%"作为技能说明中的验证依据。

#### P2-3. 交易防护参数对照（止损止盈纪律）
- **西湖原文**（趋势跟随交易法）：**−7% 硬止损**；分批止盈 20%/25%/30%；强势领导股 1–3 周涨20%不抛；熊市/震荡市止损收紧至 **5%**、预期降至 **10–15%**；跌破趋势线一股不留；**永不下摊成本**；加仓后利润回吐至成本线无条件清仓。
- **我方现状**：`trade_guard.py` 已有 ATR 止损/盈亏比；分层止损铁律（−7%硬止损 / EMA13或MA10减仓 / MA20清仓 / MA50生命线）。
- **落地建议**：**一致性核对**——−7% 已吻合；补"熊市收紧至5%、预期10–15%"的**环境自适应止盈止损档**（可由 market_regime 温度驱动）。

### 🥉 P3 — 参考型增量（复用价值中低）

#### P3-1. 筹码分布量化规则
- **西湖原文**：**筹码集中度（90%成本区间）<10%** + **获利比例>80%** 且处低位 → 易走牛（低位可放宽集中度<20%）；**高位集中度≥30–40% 警惕**；低位单峰密集+放量上破=启动；跌穿高位单峰密集=止损。
- **我方现状**：已有 `chip` 数据源（westock/tdx），缺量化规则。
- **落地建议**：可建 `chip_score.py`，把"集中度+获利比例"纳入个股评分。

#### P3-2. 强势股新增 / 创新高天数（每日新晋 + 领头羊排序）
- **西湖公式**：新增 `REF(C,1)<HHV(H,250)*0.9 AND C>HHV(H,250)*0.9`；创新高天数 `COUNT(H>=HHV(H,250),20)`（板块内降序找领头羊）。
- **落地建议**：并入板块扫描（找板块内领头羊）与每日"新晋强势股"提示。

#### P3-3. 港资（北向）持股副图 → CANSLIM 的 I 要素
- **西湖原文**：`GPJYVALUE(6,1,1)` 港资持股量、占流通比；**港资持股>3%** 为基本面加分项（基金北向股池为诸多选股公式的底池）。
- **落地建议**：验证 westock 是否提供北向持股数据；可取则落地"基金北向股池"作为强度选股底池（西湖体系高频复用的基础池）。

#### P3-4. 月线反转（通达信版，供校对）
- **西湖公式**：`C/MA250>1`（站上年线）AND 30日内站上年线天数>2且<30 AND 月内创50日新高 AND **RPS50≥85** AND `HIGH/HHV(HIGH,120)>0.9`。
- **落地建议**：与 `month_frame.py` 现有"月线反转"定义**对照**，取长补短（西湖版更强调 RPS 与年线位置）。

#### P3-5. 大盘变盘的板块级信号
- **西湖原文**："**进攻板块数量骤减**"是板块退潮/变盘的明显信号；20日线占比 + 50日线占比**转向**。
- **落地产建议**：可在 `market_regime` 增加"进攻板块数量"（当日强势板块计数）作为辅助变盘信号。
