## 一、七条铁律（每条都在 `quant_scripts/btframework.py` 中强制实现）

| # | 铁律 | 原因（血泪教训） |
|---|---|---|
| **1** | **无未来函数**：第 t 根决策，特征只用 `rows[0..t]`；成交从 `t+1` 开始 | ZIG(2,15) 事件曾虚高胜率 68%→真实 54% |
| **2** | **保守成交**：同一根 K 线内既触止损又触目标 → **按止损计** | 不挑对自己有利的假设 |
| **3** | **扣成本**：双边 0.15%（印花税+佣金） | 不扣成本的高频策略全是幻觉 |
| **4** | **风险归一化**：主指标用 **R 倍数** = 收益% ÷ 止损幅度% | ⚠️本次教训：不同参数组止损幅度差异巨大（6.5% vs 10%），只比百分比收益会**把"窄止损"误判成优势** |
| **5** | **分档看单调性**：不只看均值，要看各档是否单调 | 防"选择性报告某一档" |
| **6** | **样本量门槛**：单档 < 300 标注「样本不足」，不下结论 | 小样本结论不可复现 |
| **7** | **时间切分样本外**：前段调参 / 后段验证，**两段结论不一致 = 不可信** | 防参数过拟合到某一段行情 |

### 评价指标口径（必须同时报三个）
1. **均R**（期望值）——决定长期盈亏
2. **中R / 中位%**（典型体验）——决定实盘能否拿住
3. **胜率**——决定心理承受度

> 只报均R 会忽略"多数交易小亏、靠少数大赚"的策略（如 F10×2.5ATR 中R 前段为负）；
> 只报胜率会被"小赚多次、大亏一次"的策略骗（如 rr<1 档胜率 67% 但盈亏比仅 0.45）。

## 二、框架结构（`btframework.py`）

```
DataFeed            数据源抽象（kline800.json / 可换同花顺长历史）
  .codes() .bars(code) .slice_time(lo,hi)   ← 原则7 时间切分

指标层（全部只用 <= i 的数据，原则1）
  atr_w(rows,i,n)    Wilder ATR
  ma(vals,i,n)       均线
  prev_high(rows,t,n) 前 n 日高（不含当日）
  prev_low(rows,t,n)  前 n 日低

模拟层（原则2/3）
  simulate(rows,t,stop,target,maxh,cost) → (收益, 出场原因)
     止损优先 / 触目标 / 到期收盘，三态明确

统计层（原则4/5/6）
  stats(pairs) → {n, mean_pct, med_pct, win, meanR, medR, stop_pct, thin}
  fmt(tag,s)   统一格式输出

组合层
  run_matrix(feed, setup_fn, maxh, month_filter, sample_every)
```

**用法示例**
```python
import sys; sys.path.insert(0, "quant_scripts")
from btframework import DataFeed, atr_w, prev_high, simulate, stats

feed = DataFeed("data/kline800.json")
# setup_fn(rows, t) → {"stop":…, "target":…, "label":…}
acc = run_matrix(feed, lambda r,t: {"stop": r[t][2]-2*atr_w(r,t),
                                    "target": prev_high(r,t,60), "label":"T60"}, maxh=40)
print(stats(acc["T60"]))
```

## 三、标准流程（四步）

```
① 单因素扫描   固定其它参数，只变一个维度（如 8 种目标位定义）
② 联合寻优     取①的最优前 3，与第二维度交叉（如 目标 × 止损）
③ 样本外验证   时间切分，两段均正才算通过（原则7）
④ 落地 + 存档  改代码 / 或写入 SKILL / 报告归档 docs/
```

**通过标准（三者同时满足才建议落地）**：
- 均R > 0 **且** 中R > 0（双正）
- 两段样本外均R 同为正
- 相对现状有可解释的机制（不是纯数据挖掘）

## 四、首批应用案例（2026-09-24）

### 案例1：盈亏比(rr)分档缩仓 → **被证伪，撤回**
- 假设：rr 越高越值得，应按 rr 缩仓
- 结果：**完全反向**（rr<1 均R +0.025 / rr≥5 均R -0.209）
- 机制：`目标=前250日高` 使 **rr 高的股票 = 深度回撤股**（距前高 115%），rr 实际是"深跌探测仪"
- 教训：**该改的是"目标位定义"，不是"仓位规则"**

### 案例2：执行卡出场规则 → **确认需要修改**
- 现状：`目标 = max(前250日高, C×1.08)`、`止损 = 2×ATR`
- 问题：现状组合**两段样本外不稳**（前段 -0.179R），胜率仅 38~49%
- 结论：改为 **`目标 = 前60日高`、`止损 = 2.5×ATR`**（两段均正、胜率 59.5%/63.3%、中位由 -5.5% 转 +1.6%）

## 五、常见陷阱清单（踩过就记）

1. ❌ 只比百分比收益，不做风险归一化 → 误判窄止损为优势
2. ❌ 用后复权数据判涨跌停 → 漏判（后复权抹平除权跳空）
3. ❌ 目标位设"远期前高" → 对深跌股产生虚高 rr，指标失真
4. ❌ 全样本均值 > 0 就当结论 → 必须先做分档单调性 + 样本外
5. ❌ 忽略"均R 与中R 符号相反"的组合 → 实盘拿不住
6. ❌ 样本按"当前成分股"取 → 幸存者偏差
