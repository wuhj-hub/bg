## 一、工具 1：市场监控雷达（大盘宽度）

| 项目 | 口径 |
|---|---|
| **三线全景** | 沪深全市场**站上 MA5 / MA50 / MA250** 的个股占比 |
| **双预警线** | **75% 超买** / **25% 超卖** |
| **BTI 广度指标** | 广度量值（文中示例 54.2） |
| **刷新频率** | 交易日 9:00–15:00，**每 15 分钟** |
| **历史回溯** | 可回看过去一年 |

**示例读数（2026-08-26）**：站上 5 日 **75.58%**（176/5525）、站上 50 日 **57.72%**（3189/5525）、BTI **54.2**

> 🎯 **这是我方已有能力的同源口径**：我们的 `yearline_breadth`（站上年线比例）= 它的 MA250 线；我们的 `market_width`（涨跌家数+宽度分）= 它的 BTI 思路。
> **但它多了一个我们没有的东西：MA5 线与 75%/25% 预警线** —— 短期超买超卖的直接刻度。

## 二、工具 2：智能诊股引擎

### 2.1 Tab1「个股综合评分」——满分 85 分

**分档**：`≥65 买入` ｜ `50-64 值得关注` ｜ `40-49 观望` ｜ `<40 回避`

**评分模块**（净得分 = 加分合计 − 扣分）：

| 模块 | 得分 | 说明 |
|---|---|---|
| CANSLIM 选股 | **+23 / 40** | 七要素 |
| **趋势阶段** | **+20 / 20** | 温斯坦四阶段，二阶段成立则满分 |
| 买点时机 | **+10 / 25** | 口袋支点 |
| 风控扣分 | 最多 **−8** | 0 表示无扣分 |

**CANSLIM 七要素的具体阈值**（这是他公开的最细颗粒度）：

| 要素 | 阈值 | 得分 |
|---|---|---|
| **C 当季收益** | 净利润同比 **≥25%**，且**环比加速** | +6 |
| **A 年度增长** | **CAGR ≥25%** 加 4 分；**ROE ≥17%** 加 1 分 | +4 |
| **N 新高/新驱动** | 距 250 日高点适中 | +2 |
| **S 供求/筹码** | 近 30 日**上涨量 / 回撤量 > 1** | +2 |
| **L 领导者 RPS** | **两线红：120 日 + 250 日 RPS 均 ≥90** ★★ | **+8**（权重最高）|
| **I 机构认同** | **港资持股 ≥3%** 起步关注 | +1 |

> ⭐ **L（两线红 RPS）单项 +8，是七要素中权重最高的** —— 再次印证该体系"RPS 优先一切"。

### 2.2 ★ 趋势阶段：温斯坦二阶段 **6 项确认条件**（可直接量化）

**6 项全部通过 → 二阶段主升成立（+20 满分）**：

```
① 收盘价 > 50日均线
② 50日均线 > 150日均线
③ 50日均线 > 200日均线
④ 收盘价较 200日最低收盘价 涨幅 > 30%     ← 脱离底部
⑤ 收盘价较 200日最高收盘价 跌幅 < 25%     ← 不在深调中
⑥ RS1（52日相对强度）> 0                  ← 强于大盘
```

> 🎯 **这 6 条是本报告最大的可落地资产**：逻辑自洽、阈值明确、纯日线可算。我们的 `month_frame.py` 做的是月线级闸门，**但缺一个日线级的"第二阶段"判定**——这 6 条正好补这个位。

### 2.3 Tab2「口袋支点量化分析器」

**支点评分**：`S级 ≥85` ｜ `A级 70-84` ｜ `B级 55-69` ｜ `C级 48-54` ｜ `D级 <48`

**识别漏斗（6 步检测，全绿才确认）**：

```
① 大盘环境   → 评级（示例 D 级 → 观望/空仓 0-2成）
② 个股阶段   → 二阶段主升（复用上面 6 条件）
③ 均线排列   → 多头：MA5 < MA10 < MA20 < MA50
④ 形态位置   → 回踩 MA10（示例 ±0.0%）
⑤ 量能确认   → 量能比 = 当日量 / 前10日下跌日最大量；另比 50日均量倍数
⑥ 确认/止损  → 支点后守住低点
```

**止损体系（分层，这是他明确写的"铁律"）**：

```
-7%          ← 硬止损铁律（或支点当日最低点）
跌破 EMA13 / MA10  → 减仓
跌破 MA20          → 清仓
跌破 50日线        → 二阶段生命线，趋势可能终结
```

**两个实例**（可用来校准我们的实现）：

| 案例 | 关键数据 |
|---|---|
| **乔锋智能 301603** | 现价 131.99(+10.4%)｜RPS 50/120/250 = **38 / 98.2 / 95.8**（两线红）｜RS1 +9.53%｜距一年新高 −18.2%｜二阶段主升｜**综合 53 分（关注）**｜支撑：EMA13 122.6 → MA10 123.9 → MA20 120.95 |
| **药明康德 603259** | 现价 159.94(+0.4%)｜RPS = **98.9 / 98.2 / 92.4**｜RS1 +19.27%｜距新高 −7.9%｜**支点 65 分（B级）**｜量能比 1.20（1.44倍50日均量）｜近30日 3 个支点（08-04/08-05/08-07）|

## 四、可吸收增量（按性价比排序）

### 🥇 1. 温斯坦二阶段 6 条件（最值得做）

**理由**：纯日线、阈值明确、开源无争议；能补上我方"日线级趋势准入"的缺口。
**落点**：新建 `stage2_check.py`，作为所有日线买点信号的**前置过滤器** —— 只在二阶段成立时放行。

### 🥈 2. 市场宽度三线 + 75/25 预警线

**理由**：我方 `yearline_breadth`（MA250）已验证（8/21 = 22.6% bear 级），**补 MA5/MA50 两条线成本极低**，且能直接复用现有数据。
**落点**：扩展 `market_width.py` 输出三线占比 + 预警状态。

### 🥉 3. 分层止损（EMA13 → MA10 → MA20 → 50日线）

**理由**：我方 `trade_guard` 是"ATR + 盈亏比"的单点止损，**缺"分级减仓"**。该体系的分层（减仓→清仓→生命线）更贴合持有过程。
**落点**：`trade_guard.py` 增加分级告警。

### 4. CANSLIM 七要素评分（长期）

**理由**：我方完全没有基本面维度，这是**结构性缺口**。但需要财务数据源（当前沙箱取财务数据受限）。
**落点**：先做 C/A 两项（净利润同比、CAGR、ROE），后续再补。

### 5. 标准 RPS 体系（50/120/250）

**理由**：该体系"RPS 优先一切"，而我方只有相对强度的变体。
**落点**：用同花顺长历史数据自算 RPS（我们已有 868 只周线 + `kline_daily_qfq.csv` 3070 只日线）。
