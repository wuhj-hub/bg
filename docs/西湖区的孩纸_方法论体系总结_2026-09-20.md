## 一、该号在内核上说了什么（最有价值的一段原文）

小西在《2021-11-11 对于口袋支点的个人总结》里，用 5 条讲清了整套框架：

> 🟩 **原文**："口袋支点这个每个人都有不同的标准……但是我可以基于自己的经验给出几个条件会大大提高成功的概率：
> **a**：口袋支点的形成最好符合处于**第二阶段**的……
> **b**：口袋支点个股的 **rps 强度不能太弱**……
> **c**：要注重**板块效应**或者出现口袋支点的个股属于**板块 rps 较强**的概念板块中……
> **d**：出现口袋支点的个股形态一定要多看看**周线**，周线 **macd 是绿的，效果要大打折扣**，周线 macd **刚刚翻红的，成功率会提高很多**……
> **e**：口袋支点出现在上升的基底**越高，失败概率越大**，最好是处于上升形态的**第二或者第三个基底**。"

**这段话就是"大周期找趋势，小周期找买点"的全部含义**，浓缩成一条链：

```
板块(RPS)  →  周线(阶段/MACD)  →  日线(口袋支点)
   ↑ 趋势在哪      ↑ 能不能做        ↑ 今天扣不扣扳机
```

## 五、可落地的量化规则（🟦 综合归纳）

**市场层**：指数中期信号不成立 → 不开新仓；成立 → 正常仓位
**板块层**：只在板块 RPS 排名靠前的赛道里选股
**个股层**：30周线之上 + 周线 MACD 翻红（**"刚刚翻红"效果最好**）
**买点层**：口袋支点 / 首次回踩 10·20·50 日线 / 净利润断层后首阳
**位置层**：**阶段最大调整不超 −46%**（`L120/H120>0.54`）；**基底越高失败率越大**（选第2/3个基底）
**止损层**：三重滤网版 = 前一期K线实体最低价下方；单笔风险 ≤ 总资金 2%

## 六、⭐ 与我方体系（bg）的对照：4 个可吸收增量

| # | 增量 | 价值 | 建议落点 |
|---|---|---|---|
| **1** | **净利润断层**（业绩跳空 + 缺口不补 + 放量） | 我方**完全缺失**；且与"第二波"逻辑契合 | 新建扫描器，接入盘前/复盘 |
| **2** | **口袋支点的量能判据**（`AMO=HHV(AMO,10)`） | 具体、可直接复用；比我方"倍量柱"更贴近机构行为 | 与王者倍量柱对照融合 |
| **3** | **位置约束**（`L120/H120>0.54`，即阶段调整 ≤−46%；基底越高越差） | 我方有"回撤>40%"（周线放量扫描器），**方向一致但口径不同** | 交叉验证哪种更优 |
| **4** | **RPS 扩展数据体系**（50/120/250 三层 RPS + 板块 RPS） | 我方有 RSL/RS_D，但**没有完整的三周期 RPS 体系** | 补齐，用于板块与个股排序 |

**特别值得注意的呼应**：
- 该体系强调"**周线 MACD 刚刚翻红**成功率最高" —— 与我们昨天验证的"**底部周线温和放量**"是同一类思路（都是找趋势刚起步、不追高）
- 该体系的"基底越高失败率越大" —— 与我们回测出的"**月线已牛时买入是追高（−1.93%）**"完全一致
- **两个独立体系在"A股不能追高"上得出相同结论**，这条经验可以更放心地用
