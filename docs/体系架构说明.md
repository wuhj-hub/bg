## 一、体系总览

**一句话定位**：`温度计决定做不做 → 风格轴决定做什么风格+多少仓位 → 三阶漏斗决定做哪只 → 四维证据链决定敢不敢重 → 组合层控全局风险 → 交易防护决定怎么走 → 报告体系闭环验证`

**四层架构**：

```
┌──────────────────────────────────────────────────────────────┐
│ ① 市场环境层 —— "能不能做、做什么风格、多少仓位"                     │
│   鱼身温度(开关·<40暂停/>80沸点减仓) │ 猛兽安全评分(刻度)             │
│   双弦温度(方向) │ 市场宽度+涨停池代理(炸板率/连板)                  │
│   市场风格轴(指数市/均衡/情绪市) → A3仓位映射(±10%)                  │
│   猛兽双模式聚合(堆量/欧马) → 与风格轴交叉验证                       │
├──────────────────────────────────────────────────────────────┤
│ ② 选股链路层 —— "做哪只"（三阶漏斗+交易防护+组合风控）              │
│   月线反转(趋势确认) → 武威G1(低吸潜伏) → v2.1(质量否决)            │
│   ★三重共振/二阶/一阶/否决 + trade_guard 防护层                     │
│   B2组合层：单票≤15%/板块≤30%/同向≤5/持仓≤5；≥2只离场→组合降仓      │
├──────────────────────────────────────────────────────────────┤
│ ③ 信号系统层 —— "用什么信号"                                      │
│   猛兽(领先/回调/G点/伏击/断层) │ 鱼身(空中加油/回踩/突破)           │
│   武威G1 │ 乾坤A级金股(第四信号源) │ 反转数值/2B │ 四维共振(全市场)  │
├──────────────────────────────────────────────────────────────┤
│ ④ 输出与自动化 —— 报告 + 推送 + 知识库                           │
│   盘前→全盘量化→复盘→股池跟踪(含组合风控)→胜率跟踪 五环闭环          │
│   GitHub Actions 三条流水线 + PushPlus + IMA 知识库归档           │
└──────────────────────────────────────────────────────────────┘
```

## 三、市场环境层（2026-08 新增维度）

### 3.1 三个温度计（管"冷热"）

| 温度计 | 构成 | 阈值 |
|---|---|---|
| 鱼身温度 | 上证 MA5/10/20 + 10日涨跌幅 + 量比 | <40 暂停开仓 |
| 猛兽安全评分 | 上证30%+中证全指40%+深证综指30% + 量/速/广度情绪 | ≥70安全/≥55偏暖/≥40中性/≥25偏冷/<25危险 |
| 双弦温度 | 直接调猛兽 check_market_safety() | AND门控 ≥40 |

### 3.2 市场宽度（market_width.py）
全主板涨跌家数分布 → 宽度分 0-100（上涨占比 + 强势×3 + 涨停×2），等级：强势/偏强/震荡/偏弱/弱势。**情绪强弱计**。
**涨停池代理**（2026-08-10，无涨停池接口自算）：批量K线 limit 3 计算 触板(盘中最高≥前收×1.10×0.99)/炸板(触板未封)/二连板(今昨均涨停) → `limitup_stats`（炸板率<20%情绪健康 / >40%退潮预警），输出至宽度JSON与MD，风格轴B轴消费（炸板率<20%+4分 / >40%-8分）。8/10实测：触板131/炸板42(32.1%)/二连板11——涨停89家但炸板率32.1%提示涨停质量一般。

### 3.3 市场风格轴（market_style.py）—— 谁在涨
四轴打分 ±100：

| 轴 | 权重 | 指标 |
|---|---|---|
| A 大小盘相对强弱 | ±40 | 沪深300 vs 中证1000 5/10/20日涨幅差 + 小盘脉冲(单日>3.5%/5日>10%) + 大盘均线多头 |
| B 涨停结构与宽度 | ±35 | 涨停家数(机构市3-8/游资市>15) + 中军涨停(沪深300成分) + 强势占比 + 宽度分 |
| C 成交结构 | ±15 | 中证1000/沪深300 成交额比今 vs 5日均 |
| D 板块资金定性 | ±10 | 涨幅TOP板块 asfund 主力5日 vs 散户净流 → 机构型/游资型 |

**三态判定**：≥+25 → 🔥情绪市（游资主导·主扫堆量/G1低吸·防A杀）；≤-25 → 🏦指数市（机构主导·主扫乾坤金股/欧马·趋势持股）；中间 → ⚖️均衡市。

### 3.4 猛兽双模式交叉验证（beast_screener.py Step 6）
统计当日猛兽信号的堆量/欧马分布 → 与风格轴交叉：情绪市+堆量 或 指数市+欧马 = ✅强共振；反向 = ⚠️背离。**次级确认**（热搜候选池样本小）。

## 四、选股链路（三阶漏斗 + 交易防护）

```
① 月线反转      趋势确认（平台突破12月新高/均线金叉/趋势确立）   month_frame.py
② 武威G1        低吸潜伏（双阴/一阴缩量回调，支撑≥5%）          wuwei_scan_month.py
③ v2.1质量否决   盈利过滤（亏损股一票否决）                      wuwei_v21_filter.py
─── 交易防护层 trade_guard.py ───
ATR(14)止损(收盘-2×ATR) │ 盈亏比≥2门槛 │ 牛熊动态仓位 │ 离场计分卡(持仓≤-2强制离场)
```

**决策分级**：★三重共振（买）→ 二阶 → 一阶观察 → 否决。

**A3 仓位动态化**（2026-08-10）：`build_judgment` 仓位 = 基准(三系统≤30/40/50%) + 风格分修正(情绪市≥+25→+10% / 指数市≤-25→-10%) + 温度修正(鱼身>80沸点→-10%)，clamp 10%~70%；情绪市附"主扫堆量/G1"、指数市附"主扫欧马/乾坤"偏好。每日 premarket_judgment JSON 记录 style_score/base_pos/style_fix/temp_fix/final_pos 供 2-4 周后验证。

**B2 组合层风控**（2026-08-10）：`pool_tracking_report.py` 六章组合层——默认约束 单票≤15% / 板块≤30% / 同向≤5只 / 持仓≤5；估算总仓位(单票15%×持仓数)；≥2只持仓触发离场卡 → 🔴组合降仓信号(总仓位≤30%) + 独立 PushPlus 推送。8/7验证：3只持仓2只离场 → 组合降仓正确触发。

1. **连板高度/炸板率无数据源**（westock无涨停池接口），涨停结构以"涨停家数+中军"代理
