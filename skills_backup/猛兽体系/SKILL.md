## 月线框架模块（month_frame.py · 曾星智+陶博士体系）

```bash
python3 scripts/month_frame.py --self-test    # 内置样本自测
python3 scripts/month_frame.py --check sz000026   # 单股月线检查
python3 scripts/month_frame.py --scan sh603259,sz000026   # 批量
```

**核心规则**（对应盘前报告曾星智体系口径）：
- MA6 = 近6个月收盘均值（半年线）；MA12 = 近12个月收盘均值（年线）
- 多头: 收盘>MA6 且 MA6>MA12；空头: 收盘<MA6 且 MA6<MA12；其余纠缠
- **月线反转信号**（大周期趋势转强第一确认）：
  - 平台突破: 本月收盘创近12月新高且站上MA6
  - 均线金叉: MA6本月上穿MA12
  - 趋势确立: MA6持续上行且价格在其上方
- **月线闸门**: PASS(多头/反转→日线买点可靠) / WARN(纠缠→降级) / BLOCK(空头→日线信号可靠性低)

**集成点**：
- 猛兽 Step 2.6：候选池逐只月线检查，输出反转信号统计；领先股/回调股表格带月线列
- 鱼身：日线三模式信号增加月线确认标注（⚡反转/🟢多头/🟡纠缠/🔴空头）
- 盘前报告 ④.3：premarket_beast.py 解析月线反转信号专表
