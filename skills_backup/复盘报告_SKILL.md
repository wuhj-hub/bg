# 📊 复盘报告 Skill

**功能**：每日收盘后，读取今日盘前报告的预判 + 盘后量化原始扫描数据，验证盘前策略准确性，整合全市场资金分布，给出明日展望。

**定位**：本报告是整个投资闭环的**收口环节**
```
盘前报告(N-1) ──→ 盘前报告(N) ──→ 交易时段 ──→ 全量扫描(后台数据) ──→ 复盘报告(N)
   ↑引用昨复盘       ↑给今日策略         ↑实际走势        ↑原始资金数据      ↑验证+整合+展望
                                                                                ↓
                                                                         盘前报告(N+1)
```

## 执行流程（SOP）

### Step 1：读取今日盘前报告

从「报告」知识库「盘前报告」文件夹获取今日的盘前报告内容：

```bash
# 搜索今日盘前报告 media_id
search(source="kb", kb_id="6kjd8jHpAyqf0xFVUo2xUWPaDAKapAWCw-Tki7V-aAs=", question="盘前市场报告_当前日期")

# 获取 media_id 后用 fetch 读取
fetch(type="media_id", id="<media_id>")
```

提取以下关键预判：
- 🎯 信号快照卡（鱼身温度、猛兽评分、双弦方向、操作基调）
- 📊 大盘定势判断
- 🗂️ 板块关注方向
- 🎯 个股关注清单
- ⚠️ 预警规则触发
- 📋 操作建议（仓位、止损等）

### Step 2：读取今日盘后量化原始数据

从「报告」知识库「复盘报告」文件夹获取今日的全量扫描数据：

```bash
# 搜索今日盘后量化数据
search(source="kb", kb_id="6kjd8jHpAyqf0xFVUo2xUWPaDAKapAWCw-Tki7V-aAs=", question="盘后量化_当前日期")
```

提取以下核心数据：
- 📊 双维定性分布（情绪退潮/游资情绪/主力占比）
- 📋 重点标的 Top20-50（按信号强度排序）
- 🔥 主力信号标的详情

### Step 3：盘前预判验证

对盘前报告的每个关键判断进行验证：

| 验证项 | 盘前判断 | 收盘实际 | 结果 |
|:-------|:---------|:---------|:----:|
| 大盘方向 | 盘前结论 | 今日实际涨跌 | ✅/❌/⏳ |
| 操作基调 | 进攻/防守/空仓 | 全市场情绪退潮占比 | ✅/❌ |
| 板块主线 | 盘前关注方向 | 实际涨幅 + 资金分布 | ✅/❌ |
| 个股信号 | 关注标的 | 实际涨跌 | ✅/❌ |
| 预警触发 | 触发项 | 实际表现 | ✅/❌ |

**评分原则**：
- ✅ 准确：预判与实际情况一致
- ❌ 偏差：预判与实际情况相反
- ⏳ 待验证：需要更多交易日确认

#### 3.1 信号次日表现统计（新增·signal_verify模块）

基于昨日盘前报告中提取的推荐标的，查询今日日K线数据，统计量化维度的「次日表现验证」：

```bash
# 自动读取昨日盘前报告 → 提取标的 → 查询今日K线 → 输出验证报告
python3 /sandbox/workspace/skills/盘前市场报告/scripts/signal_verify.py
```

输出包含：
- **汇总**：统计标的数、次日冲高胜率、收盘胜率、平均次日最高涨幅、≥3%/≥5%标的数
- **排行**：按次日最高涨幅排序的个股明细表（含前收/今开/最高/最低/收盘/涨跌幅）
- **结论**：信号质量评级（🟢优秀 / 🟡一般 / 🔴偏差）

> ⚠️ 次日最高涨幅为盘中最大值，不代表实际能卖在最高点。
> 若昨日盘前报告不存在（如非交易日），自动提示跳过后不影响报告完整性。

### Step 4：量化系统信号复盘

#### 4.1 双弦系统
- 月度股池中的个股今日表现（涨跌幅）
- 大盘牛熊定性是否准确

#### 4.2 鱼身系统
- 今日9个信号（空中加油/均线回踩）的表现
- 是否触发止损位

#### 4.3 猛兽系统
- 领先股今日表现
- 安全评分实际走势

### Step 5：盘后量化深度分析

基于今日收盘的全量资金扫描数据：

#### 5.1 全市场资金全景
- 双维定性分布解读（主力/游资/退潮占比）
- 与前一交易日对比趋势

#### 5.2 重点标的追踪
- 主力主导放量标的（最强信号）
- 游资情绪标的（短线博弈）
- 是否与盘前关注方向重合

#### 5.3 多系统交叉验证
- 双弦股池 vs 盘后量化信号交集
- 鱼身标的 vs 盘后量化信号交集
- 猛兽领先股 vs 盘后量化信号交集

### Step 6：明日展望

基于今日数据给出明日操作建议：

| 维度 | 明日关注 |
|:----|:---------|
| 🔥 主力信号延续性 | 今日主力信号标的能否持续 |
| 🔴 情绪退潮变化 | 退潮占比是否改善（降到60%以下为好转信号） |
| 🐟 鱼身信号验证 | 止损/止盈触发情况 |
| 🐅 猛兽安全评分 | 评分变化趋势 |
| 📅 重要事件 | 关税宣布、新股申购、宏观数据 |

#### 6.1 尾盘资金异动（新增·closing_scan模块）

从今日盘后全量扫描数据中提取候选标的，结合60分钟K线判断尾盘量价异动，生成三档排序：

```bash
# 读取今日盘后量化数据 → 提取TOP50候选 → 检查60分K线尾盘信号 → 输出异动排行
python3 /sandbox/workspace/skills/盘前市场报告/scripts/closing_scan.py --date 当前日期
```

输出包含：
- 🔥 强异动（≥60分）— 尾盘放量拉升+反转，纳入明日重点关注池
- ⚡ 一般异动（30~59分）— 观察早盘30分钟是否延续强势
- 📋 其他关注（1~29分）— 盘中异动时再介入

> 若盘后量化数据尚未就绪（全量扫描仍在跑），自动提示跳过后不影响报告完整性。

### Step 7：输出到知识库

将生成的 Markdown 报告保存为 `复盘报告_YYYY-MM-DD.md`：

```bash

  --file-path /sandbox/workspace/outputs/复盘报告_YYYY-MM-DD.md \
  --knowledge-base-id 6kjd8jHpAyqf0xFVUo2xUWPaDAKapAWCw-Tki7V-aAs=
```

上传完成后，用 search+move API 将其移入「复盘报告」文件夹（folder_7485234585035034）。

2. **验证精度**：对盘前报告的每个明确判断（大盘方向、操作基调、板块方向）逐个验证，不得模糊处理
