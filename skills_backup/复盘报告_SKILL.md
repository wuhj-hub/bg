# 📊 复盘报告 Skill

**功能**：每日收盘后，读取今日盘前报告的预判 + 盘后量化原始扫描数据，验证盘前策略准确性，整合全市场资金分布，给出明日展望。

**定位**：本报告是整个投资闭环的**收口环节**
```
盘前报告(N-1) ──→ 盘前报告(N) ──→ 交易时段 ──→ 全量扫描(后台数据) ──→ 复盘报告(N)
   ↑引用昨复盘       ↑给今日策略         ↑实际走势        ↑原始资金数据      ↑验证+整合+展望
                                                                                ↓
                                                                         盘前报告(N+1)
```

## 执行流程（SOP）

### Step 1：读取今日盘前报告

从「报告」知识库「盘前报告」文件夹获取今日的盘前报告内容：

```bash
# 获取 media_id 后用 fetch 读取
fetch(type="media_id", id="<media_id>")
```

提取以下关键预判：
- 🎯 信号快照卡（鱼身温度、猛兽评分、双弦方向、操作基调）
- 📊 大盘定势判断
- 🗂️ 板块关注方向
- 🎯 个股关注清单
- ⚠️ 预警规则触发
- 📋 操作建议（仓位、止损等）

### Step 2：读取今日盘后量化原始数据

从「报告」知识库「复盘报告」文件夹获取今日的全量扫描数据：

```bash
# 搜索今日盘后量化数据
search(source="kb", kb_id="6kjd8jHpAyqf0xFVUo2xUWPaDAKapAWCw-Tki7V-aAs=", question="盘后量化_当前日期")
```

提取以下核心数据：
- 📊 双维定性分布（情绪退潮/游资情绪/主力占比）
- 📋 重点标的 Top20-50（按信号强度排序）
- 🔥 主力信号标的详情

### Step 3：盘前预判验证

对盘前报告的每个关键判断进行验证：

| 验证项 | 盘前判断 | 收盘实际 | 结果 |
|:-------|:---------|:---------|:----:|
| 大盘方向 | 盘前结论 | 今日实际涨跌 | ✅/❌/⏳ |
| 操作基调 | 进攻/防守/空仓 | 全市场情绪退潮占比 | ✅/❌ |
| 板块主线 | 盘前关注方向 | 实际涨幅 + 资金分布 | ✅/❌ |
| 个股信号 | 关注标的 | 实际涨跌 | ✅/❌ |
| 预警触发 | 触发项 | 实际表现 | ✅/❌ |

**评分原则**：
- ✅ 准确：预判与实际情况一致
- ❌ 偏差：预判与实际情况相反
- ⏳ 待验证：需要更多交易日确认

#### 3.1 信号次日表现统计（新增·signal_verify模块）

基于昨日盘前报告中提取的推荐标的，查询今日日K线数据，统计量化维度的「次日表现验证」：

```bash
# 自动读取昨日盘前报告 → 提取标的 → 查询今日K线 → 输出验证报告
python3 /sandbox/workspace/skills/盘前市场报告/scripts/signal_verify.py
```

输出包含：
- **汇总**：统计标的数、次日冲高胜率、收盘胜率、平均次日最高涨幅、≥3%/≥5%标的数
- **排行**：按次日最高涨幅排序的个股明细表（含前收/今开/最高/最低/收盘/涨跌幅）
- **结论**：信号质量评级（🟢优秀 / 🟡一般 / 🔴偏差）

> ⚠️ 次日最高涨幅为盘中最大值，不代表实际能卖在最高点。
> 若昨日盘前报告不存在（如非交易日），自动提示跳过后不影响报告完整性。

### Step 4：量化系统信号复盘

#### 4.1 双弦系统
- 月度股池中的个股今日表现（涨跌幅）
- 大盘牛熊定性是否准确

#### 4.2 鱼身系统
- 今日9个信号（空中加油/均线回踩）的表现
- 是否触发止损位

#### 4.3 猛兽系统
- 领先股今日表现
- 安全评分实际走势

### Step 5：盘后量化深度分析

基于今日收盘的全量资金扫描数据：

#### 5.1 全市场资金全景
- 双维定性分布解读（主力/游资/退潮占比）
- 与前一交易日对比趋势

#### 5.2 重点标的追踪
- 主力主导放量标的（最强信号）
- 游资情绪标的（短线博弈）
- 是否与盘前关注方向重合

#### 5.3 多系统交叉验证
- 双弦股池 vs 盘后量化信号交集
- 鱼身标的 vs 盘后量化信号交集
- 猛兽领先股 vs 盘后量化信号交集

#### 5.4 热点情绪复盘（新增·hot_emotion模块）
收盘后用通达信 tdx_screener 涨停数据跑热点情绪模块，验证当日题材生态：

```bash
# 第一步：IMA 会话中调用 tdx_screener 导出涨停数据（"涨停"按total翻页 + "2连板以上"），合并存为 outputs/tdx_{date}.json
# 第二步：运行热点情绪模块（自动累积历史，输出连板梯队/主线判定/退潮预警）
python3 /sandbox/workspace/skills/盘前市场报告/scripts/hot_emotion.py --date {date} --input outputs/tdx_{date}.json
```

嵌入复盘报告内容：
- **情绪温度**（0-100：涨停家数20+连板高度45+连板占比35）与昨日对比（升温/降温）
- **连板梯队**：最高板/连板家数/涨停家数 + 各板位个股明细（几天几板·板型）
- **主线判定**：强主线/持续主线/一日游⚠️（涨停多+连板少）/发酵中 + 连续上榜天数
- **退潮预警**：情绪退潮（涨停多但连板腰斩）/高度退潮（最高板下降）/主线退潮（TOP题材减半）

**盘前验证应用**：与盘前报告②.5（昨日情绪温度）对照——盘前若提示"中性/谨慎接力"，当日实际连板高度或主线是否验证；将结论写入 Step 6 明日展望（情绪升温→题材接力空间打开 / 情绪降温→继续回避追高）。

> 若 tdx 数据不可用（接口异常/非交易日），标注占位，不影响报告完整性。

#### 5.5 年线广度复盘（市场牛熊结构 · 中期）

读取当日年线广度指标（yearline_breadth.py），验证市场牛熊结构变化：

```bash
# 读取当日结构化数据（盘前/独立任务已生成）
python3 /sandbox/workspace/yearline/yearline_section.py --json /sandbox/workspace/yearline/outputs/yearline_breadth_latest.json
```

复盘要点：
- **结构对比**：今日站上年线占比 vs 历史序列（2026-04底2923/05底2166/06底1603/07底863，全A口径），判断广度趋势（恶化/企稳/修复）
- **临界标的**：距年线最近的前5只（突破=广度修复信号 / 跌破=结构恶化信号），关注其后续走向
- **结构验证**：与盘前/复盘的市场宽度（日频温度）、大盘温度计交叉验证——"温度回升但年线广度持续低位"= 超跌反弹性质（非反转）

> 若 yearline_breadth_latest.json 缺失（未运行），标注占位，不影响报告完整性。

### Step 6：明日展望

基于今日数据给出明日操作建议：

| 维度 | 明日关注 |
|:----|:---------|
| 🔥 主力信号延续性 | 今日主力信号标的能否持续 |
| 🔴 情绪退潮变化 | 退潮占比是否改善（降到60%以下为好转信号） |
| 🐟 鱼身信号验证 | 止损/止盈触发情况 |
| 🐅 猛兽安全评分 | 评分变化趋势 |
| 📅 重要事件 | 关税宣布、新股申购、宏观数据 |

#### 6.1 尾盘资金异动（新增·closing_scan模块）

从今日盘后全量扫描数据中提取候选标的，结合60分钟K线判断尾盘量价异动，生成三档排序：

```bash
# 读取今日盘后量化数据 → 提取TOP50候选 → 检查60分K线尾盘信号 → 输出异动排行
python3 /sandbox/workspace/skills/盘前市场报告/scripts/closing_scan.py --date 当前日期
```

输出包含：
- 🔥 强异动（≥60分）— 尾盘放量拉升+反转，纳入明日重点关注池
- ⚡ 一般异动（30~59分）— 观察早盘30分钟是否延续强势
- 📋 其他关注（1~29分）— 盘中异动时再介入

> 若盘后量化数据尚未就绪（全量扫描仍在跑），自动提示跳过后不影响报告完整性。

## 执行规范

1. **首尾闭环**：复盘报告必须引用今日盘前报告 + 盘后量化原始数据，三者形成「预判→数据→验证」链条
2. **验证精度**：对盘前报告的每个明确判断（大盘方向、操作基调、板块方向）逐个验证，不得模糊处理
3. **数据新鲜度**：若盘后量化原始数据尚未生成（扫描仍在跑），标注"⏳ 全量扫描进行中"，仅基于盘前报告+已知数据出初步复盘
4. **明日展望**：必须有明确的明日操作建议，不得以"关注走势"等模糊表述收尾
5. **报告日期**：以平台 `<current_time>` 提供的日期为准
6. **盘后量化数据引用**：③.5章的盘后量化数据来源为知识库中 `盘后量化_YYYY-MM-DD.md` 文件，若不存在则标注占位符。**组合层风控**（B2·2026-08-10）：pool_tracking_report.py 新增「六、组合层风控」章节（持仓数量≤5 / 估算总仓位单票15% / 触发离场统计），≥2只持仓触发离场卡 → 🔴组合降仓信号（总仓位≤30%）并独立 PushPlus 推送；约束默认：单票≤15% / 单一板块≤30% / 同向≤5只
6.5 **乾坤A级金股**：④章在主力信号专表后输出「👑 乾坤A级金股」（第四信号源：资金强攻+业绩共振），数据源为 GitHub Actions 每日生成的 `qiankun_a_latest.json`（full_market_dualdim 乾坤分级矩阵A级，按综合评分排序TOP15）；指数市环境下权重提升
7. **市场风格轴**：③章在市场宽度之后输出「市场风格轴」（指数市/均衡/情绪市：机构主导 vs 游资主导），数据源为 GitHub Actions 每日生成的 `market_style_latest.json`（market_style.py：大小盘相对强弱+涨停结构+成交结构+板块资金定性，映射《判断板块是"机构主导"还是"游资主导"》五大标准）。**涨停池代理**（2026-08-10）：无涨停池接口，market_width.py 用全主板批量K线(limit 3)自算触板/炸板/二连板 → `limitup_stats`（炸板率<20%情绪健康+4分 / >40%退潮-8分）接入风格轴B轴。若无数据标注占位，不影响报告完整性
7.5 **四维共振评分**：③.7章输出「四维共振评分」（政策/资金/筹码/关联方四维独立证据链），数据源为 GitHub Actions 每日生成的 `四维共振_latest.json`（quad_resonance.py：资金=四态抢筹3/吸筹2/进场1+沉淀率兜底；筹码=chip获利盘≥70%→3+集中度<15加成；关联方=龙虎榜机构3/游资2+大宗溢价2/平价1；政策=--policy人工研判默认0）。分级≥10★★★必然/7-9★★高置信/4-6★弱共振/≤3无；反向否决=资金0+关联方减持/净卖。**资金四层验证**（黑石启发·2026-08-10落地）：quad_resonance 对每只标的拉 asfund 当日/5日/10日/20日主力净流 → 输出 fund_tag 标签：⛔出货(四层全负·规避) / 🌀回调洗盘(当日负但20日控盘正·可低吸) / 📈资金共振(当日+20日双正) / ⚖️中性，展示于③.7"资金四层(日/5/10/20日·亿)"列。**市场温度沸点规则**（2026-08-10落地）：鱼身温度>80 标注"🔥沸点(减仓止盈)"、<40 标注"❄️偏冷(暂停开仓)"、60-80 标注"🌡️偏热"，应用于①大盘全景三系统行与③.6鱼身行。独立报告《四维共振_YYYY-MM-DD.md》上传「报告」KB全盘量化文件夹(folder_7485264708529742)。若无数据标注占位，不影响报告完整性。**板块共振加成**（2026-08-11）：四维评分命中板块共振主线中军（zhongjun_candidates）的标的 +1 分并标注🎯板块中军（β前置：板块已启动个股优先，8/11验证招金黄金9→10分升必然级）。**六套信号仲裁**（B1·2026-08-11）：③.8章输出「六套信号仲裁」——signal_arbiter.py 对四维/猛兽Setup/鱼身/双弦/乾坤五源统一打分（四维高置信+3/猛兽Setup≥60+3/乾坤A+2/鱼身加油≥70+2/伏击RS_D G点+1/双弦+1/四维否决-3），分级≥7★★★(≤15%)/5-6★★(≤10%)/3-4★(≤5%)/<3观察；TOP20逐只月线闸门校验（BLOCK强制降级）；独立报告《信号仲裁_YYYY-MM-DD.md》。**创业板/科创补充通道**（2026-08-11 代表性优化A）：gen_mainboard.py --universe chinext_kcb 生成创业板300/301+科创688清单（all_chinext_kcb.csv）→ quad_resonance.py --pool all_chinext_kcb.csv --out-prefix 四维共振_chinext_kcb 独立输出（不覆盖主板版），捕捉胜宏科技/江波龙/长鑫科技类标的
