# 强势体系 v1.0 — 强势突破买入 + 趋势跟踪止盈

一套"不等待回落"的 A 股日内/波段操作体系：在强势环境中，捕捉已经启动的突破/中继形态直接买入，并用趋势破位（而非预设目标位）来止盈，让利润奔跑。

## 与现有体系的关系
- **鱼身 / 猛兽 / 双弦**：提供环境与板块过滤、多维评分、股池积累。强势体系在其"强势分支"（空中加油/箱体突破/高阳/断层）上做**买入决策 + 止盈执行**的闭环。
- **武威（月线筑底）**：是"等回踩低吸"的潜伏体系，与强势体系哲学相反——切勿用突破追涨去套月线底部票（回测已验证错配，胜率极低）。

## 买入四关（全部满足才动手）
1. **环境关（过滤器）**：大盘温度计 ≥ 40（或等价于上证指数站上 MA60），否则任何信号都不开仓。
2. **形态关（取任一，均"不回落"）**：
   - 空中加油：MACD 在 0 轴上方，DIF 回踩 DEA 不破、柱体翻红
   - 箱体突破：前 20 日窄幅（高/低 < 18%）后放量突破前高、站上 MA20
   - 高阳快速推升：近 3 日累计涨幅 > 8% 且放量
   - （进阶）净利润断层：业绩跳空 + 放量
3. **量价关**：突破/启动日放量，量比 ≥ 1.5（或倍量），主力净流入 > 0。
4. **评分关**：综合评分达标（鱼身综合分 ≥ 55，或猛兽 Setup 在突破/高阳/孤狼维度拿分）；强势形态信号本身即视为技术达标。

## 止盈规则（趋势跟踪，不等回落）
1. **移动止损（核心）**：收盘价跌破 MA20 → 卖出（短线可用 MA10）。
2. **信号失效**：MACD 死叉（DIF 下穿 DEA）/ 柱体翻绿 → 立刻止盈。
3. **量价见顶**：高位巨量长上影 / 放量滞涨（量增价不涨）；MACD 红柱连续缩短两日以上。
4. **环境降级**：大盘温度计跌破 40 → 全部减仓/离场。

## 已知方法学局限
- 买点判定偏灵敏（高阳/箱体在震荡市易触发假突破），宽松可操作比例会虚高；应以"环境关 + 评分关"严格过滤。
- 止盈严格 MA20 在弱市会快速破位致小亏止损，需配合环境关降低出手频率。
- 本体系在牛市/结构性行情、已启动强主线上最有效；月熊环境 + 潜伏票上胜率极低（见示例回测报告）。

## 附录 A：月底选股（武威体系）验证与方法 —— 环境关未过时如何操作
当月线选股（武威 App 月末扫描）结果出来、但大盘环境关未通过（月熊/震荡）时，**不要用本体系追涨**，改用武威"月线筑底 + 等回踩低吸"体系。已用 2026-03~06 共 4 月底 82 只样本验证，规律见 `outputs/月底选股_武威体系验证与操作手册_2026-07-17.md`。

**三条铁律（强验证）：**
1. 支撑深度 < 3% 一律放弃（66 只浅支撑平均持有 -14.6%，9 只深支撑 +18.1%）。
2. 必须等回踩至支撑缩量低吸（低吸 +11.23% vs 持有 -11.19%，差 22 个百分点）。
3. 亏损股（净利润<0）一票否决（盈利股上涨率 21.9% vs 亏损股 11.8%）。

**可执行脚本（固化六维评分+决策树）：**
```bash
cd /sandbox/workspace/skills/强势体系
# 1) 在 samples.json 末尾加新月份： "2026-07-31": [["代码","名称"], ...]
# 2) 一键跑批（已缓存历史K线，仅新抓本月+财务）
python3 wuwei_verify.py            # fetch + analyze
python3 wuwei_verify.py --mode analyze   # 仅重算
# 3) 看 wuwei_verify_result.json -> details[].decision：★重仓/●轻仓 即候选，取其 support(介入价)/stop(止损价)/score
```
- 介入价 = 第一支撑（年线/60日线/月线low）；止损 = 支撑×0.92（下方8%）；止盈 = 被动长线破月线支撑才走。
- 六维评分 v2.0：信号30'+支撑20'+缩量15'+基本面15'(亏损否决)+大盘5'+价格5'；<60 放弃。
- 越接近行情启动月胜率越高（6月底 42.9% > 3月 19.6% > 5月 14.3% > 4月 0%）。

**分工一句话**：环境关过 → 本"强势体系"突破追涨；环境关不过 → 武威等回踩低吸。切勿错配。
