# 📊 盘前市场报告 Skill

**功能**：每个交易日开盘前，自动生成一份覆盖全球市场、A股全面分析、行业龙头跟踪的结构化盘前报告，并发布到公开发布的知识库。

**闭环定位**：本报告是「盘前→复盘→盘前」首尾循环的起点和终点
```
复盘报告(N-1) ──→ 盘前报告(N) ──→ 交易时段 ──→ 全量扫描(后台) ──→ 复盘报告(N)
   ↑③.4引用昨日        ③.4引用昨日                          ↑引用③.4验证     ↑明日展望
                                                                               ↓
                         复盘报告(N) ──→ 盘前报告(N+1) ──→ ...
```

本 Skill 依赖以下系统 Skill 及其 CLI 工具：

| 依赖 | 用途 |
|------|------|

| **鱼身** | 读取鱼身系统昨夜扫描的量化信号（航空加油/均线回踩/箱体突破），在盘前报告中引用展示 |

| **复盘报告** | 引用昨日收盘复盘报告中的全市场资金分布数据和预判验证结论，在盘前报告③.4引入"昨日复盘→今日展望"链条 |

**量化系统层级分工**（三系统互补，嵌入四大层级）：

| 系统 | 大盘层 | 板块层 | 个股层 |
|------|--------|--------|--------|
| 🐟 鱼身 | 🌡️ 大盘温度(开关：<40偏冷暂停) | — | 🎯 三模式买点(空中加油/回踩/突破) |
| 🐅 猛兽 | 🛡️ 安全评分(刻度：三指数加权) | 📊 板块RSR排名(主线) | ⭐ Setup八维(领先/回调/断层) |
| 🔗 双弦 | 🧭 牛熊定性(快慢弦) | 🔗 行业共振验证 | 💰 月度股池(≤10元主板) |

> 信号传导：**外围(输入) → 大盘(势：开关+刻度+方向) → 板块(线：RSR主线) → 个股(点：候选→买点→强度漏斗)**。

#### 2.10.1 市场风格轴（指数市 vs 情绪市 · 机构主导 vs 游资主导）

读取收盘后 GitHub Actions 生成的市场风格轴判定（market_style.py，依赖 market_width.py 涨停名单 + hs300.csv 中军判断）：

```bash

python3 /sandbox/workspace/bg-main/market_style.py
# 输出 outputs/market_style_{date}.md + market_style_latest.json
```

判定逻辑（来源《判断板块是"机构主导"还是"游资主导"》五大标准量化映射）：
- **大小盘相对强弱**（文章标准②）：沪深300 vs 中证1000 的5/10/20日涨幅差 + 小盘垂直拉升脉冲 + 大盘均线多头 → 正分=小盘领涨（情绪），负分=大盘领涨（机构）
- **涨停结构与宽度**（文章标准④）：涨停家数（机构市3-8家/游资市>15家爆发）+ 中军涨停（沪深300成分涨停=机构）+ 强势占比 + 宽度分；连板高度/炸板率无数据源（westock无涨停池接口），以结构代理
- **成交结构**（文章标准②/③）：中证1000/沪深300成交额比变化（资金涌向中小盘=情绪）
- **板块资金定性**（文章标准③）：涨幅TOP板块 asfund 主力5日净流入 vs 散户净流出 → 机构型（主力进散户出）/ 游资型（主力出散户推）
- **③.3 板块资金三维因子（本地独立口径·自成一体）**：`sector_resonance_local.py` 用 westock 本地数据复算（无外部API依赖，独立口径非黑石复刻）：板块池=board全行业+概念+资金流榜 ∪ hot board 60（约46个）；抢筹(主力加速+板块涨)/进场(当日+5日净流转正)/吸筹(主力进散户出)/控盘(缩量高沉淀)/共振(涨幅>0且≥2因子)，输出 `outputs/板块共振_latest.json`（JSON结构兼容旧黑石版），盘前③.3直接读取；数据源=board三段(mainNetInflow/mainNetInflow5d)+hot board(pt代码)+板块asfund(散户)+板块kline量能。注：本地为独立口径，8/7实测与黑石网站共振0重叠（黑石467题材板块池 vs 本地46行业池），不做对齐校准。**主线中军捕获器**（黑石启发·2026-08-10落地）：对共振板块取板块领涨股（board leadStock列）→ search解析代码 → asfund验证5日主力净流入，输出 `zhongjun_candidates` 至板块共振JSON，盘前③.3新增"🎯 主线中军"行展示（格式：中军股(板块·5日主力亿)）
- **乾坤A级金股（第四信号源）**：full_market_dualdim.py 每日输出 `outputs/qiankun_a_latest.json`（乾坤分级矩阵A级：资金强攻+业绩共振，按综合评分排序），复盘④新增「👑 乾坤A级金股」章节展示TOP15；指数市环境下权重提升（与风格轴联动）
- **消息面逻辑深度**（文章标准⑤）：不可量化 → 报告输出人工研判项

三态判定：风格分 ≥+25 → 🔥情绪市（游资主导·主扫堆量模式/G1低吸·防A杀）；≤-25 → 🏦指数市（机构主导·主扫乾坤金股/欧马模式·趋势持股）；中间 → ⚖️均衡市（正常三阶漏斗）

**猛兽双模式交叉验证**（beast_screener.py Step 6 输出 `outputs/mode_aggregate_latest.json`）：
- 统计当日猛兽评分信号（全部/领先股/回调股/G点）的 trade_mode 分布（堆量模式=情绪+资金溢出小盘 / 欧马模式=产业+业绩成长中大盘），输出主导模式

### Step 3.5：市场阶段定性（双弦+曾星智体系）

对 8 大指数月度 K 线数据进行以下分析：

**双弦体系**（快弦 MA20 ≈ 1月MA，慢弦 MA60 ≈ 3月MA）：
- 计算每个指数的 MA60（近3月均值）
- 当前价 > MA60 且近1月>MA60 → 多头排列 (score +2)
- 当前价 < MA60 且近1月<MA60 → 空头排列 (score -2)
- 其他情况 → 纠缠阶段 (score 0)

**曾星智体系**（半年线 MA120 ≈ 6月MA）：
- 计算每个指数的 MA120（近6月均值）
- 计算 6 个月涨跌幅
- 当前价 > MA120 且半年涨 > 0 → 看多
- 当前价 < MA120 且半年跌 < 0 → 看空
- 交叉情况 → 震荡

**综合定性**：
- 多头排列指数 ≥ 6 → 🐂 牛市
- 空头排列指数 ≥ 6 → 🐻 熊市
- 多头≥4 且 空头≤2 → 偏强震荡（结构性牛市）
- 空头≥4 且 多头≤2 → 偏弱震荡（结构性熊市）
- 其他 → 宽幅震荡

同时计算各指数近5月振幅，标注高波动（>30%）、中波动（>15%）、低波动。

## 执行规范

1. 每一步采集到数据后立即解析并暂存，不要等全部采集完再解析
2. 所有涨跌幅计算使用 `(last - prev_close) / prev_close * 100` 公式
3. 港股价格用港元单位，美股用美元单位，A股用人民币单位
4. 报告生成的日期以平台 `<current_time>` 提供的当前日期为准（沙箱 `date` 命令可能比平台慢一天，切勿直接依赖 `date` 命令推算报告日期）
5. 如果当前日期是周末（周六/周日）或国家法定节假日，提示"今日非交易日"并跳过
6. 如果数据获取失败（如API超时），标注"数据获取失败"占位，不影响整体报告
7. **预运行规则**：Step 1.5 的双弦/鱼身预运行仅在有新K线数据的交易日执行，若数据已是最新则跳过以节省时间
8. **双弦月度股池为引用展示**：若双弦系统尚未运行（如月初尚无数据），②.3(牛熊定性)/④.1(候选漏斗)章自动跳过，不影响报告完整性
9. **鱼身扫描为引用展示**：若鱼身系统尚未运行或扫描结果为0信号，对应板块自动跳过，不影响报告完整性；当大盘温度 < 40（偏冷）时鱼身全池会直接暂停扫描（不输出 JSON），属正常策略，②.1章应标注"大盘偏冷·鱼身暂停开仓信号"而非视作报错
10. **股池路径**：双弦月度股池 JSON 文件位于 `/sandbox/workspace/skills/双弦投资系统/pools/pool_YYYY-MM.json`
11. **鱼身路径**：鱼身扫描结果位于 `/sandbox/workspace/outputs/fish_body_enhanced_最新.json`
12. **猛兽路径**：猛兽扫描输出文件位于 `/sandbox/workspace/outputs/beast_scan_output.txt`；premarket_beast.py 自动读取此文件并解析生成Markdown
13. **猛兽扫描为引用展示**：若猛兽体系尚未运行（输出文件不存在或超过24小时），②.2(安全评分)/③.1(板块RSR)/④.3(领先股)章显示"⏳ 猛兽体系尚未运行当日扫描"提示，不影响报告完整性
14. **复盘报告为引用展示**：③.4(全市场资金分布)引用昨日收盘复盘报告中的数据和预判验证结论，形成「盘前→复盘→盘前」首尾闭环。若复盘报告不存在（如首个交易日），③.4章标注"⏳ 复盘报告尚未生成"占位，不影响报告完整性。数据来源为知识库「报告」→「复盘报告」文件夹内的最新报告
15. **统一过滤规则**：所有个股筛选统一使用 `filter_rules.py` 中的 `is_tradable()` 判断可交易资格。当前等级为「主板+创业板精选」，即沪深主板(60/00) + 创业板TOP50(300xxx大盘股)，永久排除科创板(688)和ST。如需切换等级，修改 `filter_rules.py` 中的 `FilterLevel.CURRENT`。
