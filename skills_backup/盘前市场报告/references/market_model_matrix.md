## 三市态标准武器组合

### 🐂 牛市中继（温度≥55）→ 追强势 + 拿长线

- 主攻：武威G1双阴（77%）+ 强势体系突破 + 鱼身空中加油/箱体突破 + 乾坤A级金股 + 猛兽领先股（Setup≥50）+ ZIG锚VWAP顺势回踩
- 底仓：月线反转龙头（长持6-12月，吃翻倍）
- 节奏：突破敢追，回调敢加，持股可长（G1双阴持12月+6.47%优于短持）

### ⚖️ 震荡反弹（40-55）→ 低吸 + 波段（体系主战场）

- 主攻：月线反转/超跌（81%）+ 三重漏斗精选（61.5%）+ 武威G1低吸 + 一统天下下单背离(B) + 鱼身均线回踩 + 猛兽回调股/伏击线/RS_D + 双弦≤10元池 + 周线反转（持4周）
- 节奏：不追涨，反转信号回调介入，1-4周快进快出
- 回避：追涨连板（涨停回调背离中小盘仅39%）、强势突破（震荡假突破多）

### 🐻 熊市反弹（<40）→ 空仓为王

- 主操作：空仓等待（曾星智：空仓是最好的操作）
- 轻仓练手：5m/30m 日内超跌做T（≤20%仓）
- 唯一例外：乾坤A级（极端资金强攻可轻仓）
- 作废清单：G1/月线反转/强势突破/连板——全部假信号区
