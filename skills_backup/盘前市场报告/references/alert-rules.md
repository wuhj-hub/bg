# 智能提醒规则配置

| 规则ID | 监控项 | 条件 | 阈值 | 提醒标签 |
|--------|--------|------|:----:|----------|
| A01 | 申万行业板块 | 当日涨跌幅 | ≥ ±3% | ⚠️ 板块异动 |
| A02 | 申万行业板块 | 主力资金净流向 | ≥ ±100亿 | 💰 资金大幅异动 |
| A03 | A股四大指数 | 当日涨跌幅 | ≥ ±2% | 📊 指数大幅波动 |
| A04 | 美股三大指数 | 当日涨跌幅 | ≥ ±2% | 🌏 外围传导 |
| A05 | 自选股 | 当日涨跌幅 | ≥ ±5% | 🔔 龙头异动 |
| A06 | 自选股 | 当日成交量/5日均量 | ≥ 1.5倍 | 📈 放量信号 |
| A07 | 纽约原油 | 当日涨跌幅 | ≥ ±3% | 🛢️ 能源成本变动 |
| A08 | 伦敦金现 | 当日涨跌幅 | ≥ ±2% | 🥇 避险情绪变化 |
| A09 | 涨停/跌停家数 | 涨停>100或跌停>50 | 超阈值 | 🔥 极端情绪 |

## 提醒输出格式

每条提醒在报告中以以下格式呈现：

```
[{标签}] {标题}
{简要说明}
```

示例：
```
⚠️ [板块异动] 航天装备Ⅱ 当日涨幅 +6.92%
航天装备板块大涨，中航沈飞等龙头领涨，关注持续性。
```

## 信号分级

| 级别 | 颜色 | 含义 | 处理方式 |
|:----:|:----:|------|----------|
| 🔴 红色 | 严重 | 触发2条以上A类规则 | 报告"重点关注"区域 |
| 🟡 黄色 | 警告 | 触发1条A类规则 | 报告中单独列出 |
| 🟢 绿色 | 注意 | 触发B类规则（自选股） | 报告中简要标注 |
| ⚪ 灰色 | 常规 | 无规则触发 | 不产生额外提醒 |
