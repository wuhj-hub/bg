## 箱体突破有效性三条件（《全球第一炒股笔录》体系 · 2026-08-26新增）

> 来源：小说《全球第一炒股笔录》（独孤圣手）"中枢突破没有真假之说，只有有效突破与无效突破"
> 实现：`quant_scripts/fish_body_enhanced.py` → `box_breakout_valid()`；单测 `test_box_breakout.py`

**模式3箱体突破评分重构**：先验证突破形态（真突破+15分；假突破直接剔除），再按 fs≥55 输出。

| 条件 | 量化口径 | 不满足后果 |
|:---|:---|:---|
| ① 量能验证 | 突破日成交量 ≥ 箱体震荡均量×1.5 | "无量突破全是诱多"→ 剔除 |
| ② 回踩确认 | 突破后收盘价守住箱顶（1%容差）；收盘回落箱体内部=诱多 | "百分百诱多骗线"→ 剔除 |
| ③ 位置验证 | 箱底相对箱体形成前均价的乖离 < 30%（排除低位大涨后高位盘整再突破） | 高位突破风险→ 剔除 |

**箱体识别**：近40根（不含最近3根突破段）收盘价区间，高度<40%视为中枢。
**突破判定**：最近3根内收盘突破箱顶×1.005。
**待确认机制**：突破日为最新一根（尚未回踩）→ 标记"突破待回踩确认"，不判无效。

**信号标签**：`有效突破` / `突破待回踩确认` / 过滤记录（"🚫 箱体突破有效性过滤 N 只"）

## 市场见顶五维监测（联动 trade_guard 离场计分 · 2026-08-26新增）

> 来源：小说《全球第一炒股笔录》（独孤圣手）"五个维度里，如果同时触发三个以上，别犹豫，那基本就是顶部区域"
> 实现：`quant_scripts/top_signal.py`（输出 outputs/top_signal_latest.json）

| 维度 | 量化口径 |
|:---|:---|
| ① 量的背离 | 指数近10日创40日新高，但新高日成交额<前20日均额×90% |
| ② 龙头崩塌 | 龙头池(longtou_pool.txt)高位股破位：收盘<MA10&MA20且乖离MA60>30%，比例≥30% |
| ③ 板块轮动散乱 | 连续2日板块涨幅TOP5重合度≤1（需board快照跨日累积） |
| ④ 利空脱敏化 | 近5日出现跌幅<-1.5%且成交额>前5日均额×1.5的放量下跌（恐慌抛售） |
| ⑤ 情绪亢奋 | 当日成交额处于近250日≥99%分位（天量代理） |

**规则**：≥3维=🔴顶部区域（trade_guard 离场计分-1并升级强制提示）；2维=🟡警戒；<2维=🟢正常。
**用法**：`python3 top_signal.py`（实时） / `--backtest`（历史验证） / `--json`（供 workflow）。
**验证**：2021-08至今回测——2024-10-08 短期顶 2/3 维齐发（天量+恐慌抛售）；单维触发不足为顶；维度5牛市频繁触发印证"≥3维"规则。⚠️ westock 指数K线仅5年窗口，2015/2018顶部无法验证。
**长历史补验（2026-08-26）**：`fetch_hist_index.py` 用腾讯 `proxy.finance.qq.com` 新fqkline接口（支持日期范围，沙箱可达）拉取 3875 根日K（2010-09至今）突破窗口限制；`backtest_long.py` 补验结论——2015-06-12牛市顶1/3维[5]/2018-01-29顶0/3/2021-02-18抱团顶0/3，**指数量价三维对大顶识别率有限，维度2(龙头崩塌)/3(轮动散乱)才是顶信号主力**（依赖实时数据，需每日运行累积）；2018/2021为缩量权重顶，指数三维无法捕捉。数据文件 `data_hs300/上证指数_日K_2013至今.json`（541KB）可复用于其他历史验证。

**P0-3 三模式长历史重验（2026-08-26，30只×2013至今，fish3_backtest.py）**：
| 模式 | 信号 | 持5日胜率 | 盈亏比 | 三大顶附近胜率 |
|:----|:----:|:----:|:----:|:----:|
| 空中加油 | 4372 | 47.7% | 0.74-0.87 | 32-42% |

## 买点精度优化：黄金起爆线规则

> 来源：交易实战经验整理（"看黄金起爆线，下上下三浪"）
> 适用场景：MACD空中加油模式的入场过滤增强

### 核心定义

**黄金起爆线 = 涨停板当日的均价线（成交额/成交量）**

涨停后股价缩量调整但不破此线，构成"涨停不破买点"——说明主力仍在成本线之上，未出逃。

### 形态特征（下上下三浪）

```
第一浪（上）：涨停放量拉升  →  确立主力成本线（涨停均价）
第二浪（下）：缩量回调       →  回踩不破均价线，成交量萎缩
第三浪（上）：再次放量上攻   →  空中加油完成，起爆信号
```

### 选股过滤条件

| 条件 | 要求 | 说明 |
|:---|:---:|:---|
| ① 涨停基因 | ✅ | 近期至少1次涨停，最好是热点题材核心股 |
| ② 放量涨停 | ✅ | 涨停日放量（量比≥1.5），换手活跃 |
| ③ 缩量回调 | ✅ | 回调日成交量 ≤ 涨停日成交量×0.6 |
| ④ 不破均价线 | ✅ | 回调最低价 ≥ 涨停日均价（不破主力成本线） |
| ⑤ 题材共振 | ✅ | 核心题材为主，热门题材为辅 |
| ⑥ 位置安全 | ✅ | 周线或波段买点附近，有低进信号 |

### 在鱼身评分中的加权

当某只股票同时满足 **MACD空中加油** 和 **黄金起爆线** 规则时：

- 空中加油基础分不变（100分制）
- 附加 **黄金起爆线加分 +10 分**（计入综合评分）
- 自动标记 `[黄金起爆]` 标签，优先展示

### 注意事项

- 黄金起爆线是买点精度优化，不是独立信号——必须叠加鱼身基础模式使用
- 涨停均价线 = 当日成交额 / 当日成交量，可在行情软件中直接查看
- 若回调跌破均价线超过3天未收回，视为模式失效，放弃跟踪
- 结合大盘温度计使用，大盘温度<40时即使满足此规则也暂不开仓

- 仅交易日盘后使用 — 非交易日无新K线数据
- 扩大版扫描约2分钟（120只），全量扫描约10分钟（5000只）
- 大盘温度<40时自动拦截
- 最终评分<55的信号自动过滤
- 日志保留30天自动清理
