# 🐟 鱼身交易系统 Fish Body Trading System v1.0

## 系统概述

基于三只真实案例（日发精机/红豆股份/灵康药业）提炼的三种经典鱼身模式的量化扫描系统。

### 三种鱼身模式

| 模式 | 评分 | 案例 | 核心理念 |
|:---:|:---:|:---|:---|
| **MACD空中加油 ⭐** | 最强 | 日发精机 | MACD在0轴上方，DIF回踩DEA不破，柱体翻红 |
| **均线回踩支撑** | 稳健 | 灵康药业 | 多头排列，回调至MA10/MA20缩量止跌 |
| **箱体突破 🚀** | 动量 | 红豆股份 | 窄幅整理后放量突破前高 |

## 安装与运行

### 环境要求
- Python 3.8+
- Node.js >= 18（westock-data依赖）

### 运行命令

```bash
# 扫描核心股票池（3只）
python3 fish_body_system.py --pool core

# 扫描特定模式（1=MACD空中加油, 2=均线回踩, 3=箱体突破）
python3 fish_body_system.py --pool core --mode 1

# 使用自定义股票池
python3 fish_body_system.py --pool /path/to/stock_list.txt

# 全A股扫描（耗时较长）
python3 fish_body_system.py --pool all

# 调低评分阈值（默认60分）
python3 fish_body_system.py --pool core --threshold 50
```

### 股票池文件格式
```
# 注释行，每行一只股票代码
sh603669
sh600400
sz002520
```

## 信号评分规则

### 模式1: MACD空中加油（满分100分）
```
✅ DIF/DEA > 0（0轴上方）      → 25分
✅ DIF >= DEA（金叉状态）      → 25分
✅ MACD柱 > 0（加油成功）      → 30分（柱体刚翻红<0.15=30分，已走高=15分）
✅ 收盘 > MA5                  → 10分
✅ MA20 > MA60（多头排列）     → 5分
✅ KDJ_J < 85（未超买）        → 5分
```

### 模式2: 均线回踩支撑（满分100分）
```
✅ MA20 > MA60（多头排列）     → 20分
✅ MACD在0轴上方               → 15分
✅ 股价在MA10附近（偏离<5%）   → 25分
✅ 收盘 > MA5                  → 10分
✅ 站在布林中轨上方            → 5分
✅ 收盘 > MA120（长期趋势）    → 5分
✅ 从20日高点回调3%-15%       → 15分
```

### 模式3: 箱体突破（满分100分）
```
✅ MA20 > MA60                 → 20分
✅ MACD金叉                    → 20分
✅ KDJ金叉                     → 10分
✅ 收盘 > MA5                  → 15分
✅ 振幅收敛+突破              → 15-25分
✅ 成交量放大（>均值1.3倍）    → 10分
```

## 交易体系工作流

```
┌─────────────────────────────────────────────────────┐
│                   每日扫描流程                        │
├─────────────────────────────────────────────────────┤
│  ① 运行扫描 → python3 fish_body_system.py           │
│  ② 查看信号 → 关注80分以上的标的                     │
│  ③ 人工复核 → 检查K线形态 + 大盘环境                 │
│  ④ 制定计划 → 设定买入价/止损价/目标价               │
│  ⑤ 执行交易 → 达到条件后下单                         │
│  ⑥ 持仓管理 → 跟踪MACD/KDJ变化，按信号离场           │
└─────────────────────────────────────────────────────┘
```

## 风险控制规则（内置）

| 风控项 | 规则 |
|:---|:---|
| 🛑 硬止损 | 跌破止损价，无条件离场 |
| 📉 MACD死叉 | DIF下穿DEA，减仓50% |
| 📊 KDJ超买 | J值>95且拐头，减仓 |
| 📉 跌破MA20 | 清仓离场 |
| 📈 目标达成 | 分批止盈（第一目标50%，第二目标30%，留20%博取超额） |
