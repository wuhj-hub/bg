# 板块-个股「入牛时点」扫描

## 一、核心方法（曾星智·月线力量）

**个股牛市**（= 「5根月线全部向上」）：

```
MA5,MA10,MA20,MA30 := MA(CLOSE,5/10/20/30)
DIF := EMA(CLOSE,10) - EMA(CLOSE,22)
个股牛市 := MA5↑ 且 MA10↑ 且 MA20↑ 且 MA30↑ 且 DIF↑        {月线周期}
```

**板块（行业）牛市**：行业指数用同一规则。行业指数 = 成分股月收益**等权**合成。
**大盘环境**：全市场等权指数用同一规则。

**信号** = 状态由「非牛市 → 牛市」的**转折月**（不是牛市中每个月）。
**入场** = 信号**次月开盘**。

> ⚠️ 曾星智原话把月线的 5 根线称为"5 个长期力量"：5月线、10月线、20月线、30月线、月线 MACD 的 DIF 线。他只做到 30 月线，因为中国股市一轮牛市约 1–2 年，30 个月≈2.5 年。

## 二、分层（本技能的核心价值）

按「个股入牛月」相对「板块入牛月」的时点差 Δ 分层：

| 分层 | 含义 |
|---|---|
| Q1 | 个股与板块**入牛当月**（Δ=0） |
| Q2 | 板块入牛后 **1–3 月** |
| Q3 | 板块入牛后 **4–6 月** |
| Q4 | 板块入牛后 **>6 月** |
| M | **板块内率先**：板块每轮入牛时 [d−6,d] 窗口内最早入牛的个股（每板块每轮 1 只） |
| L | 个股入牛时**板块尚未入牛**（个股领先板块） |

## 三、止盈规则

**周线顶背离 后 跌破黄金线** → 卖出：

```
{周线顶背离(口径A,推荐)}
周价创60周新高 且 周线DIF 未创60周新高

{黄金线}
XA72 := MA(TR,13);  XA73 := REF(C,1) - REF(XA72,1);  黄金线 := HHV(XA73, 12)
```

黄金线出自「腰缠万贯」主图指标；在周线语境下使用（即用周线的 TR、C 计算）。触发顺序：先出现顶背离，之后某周收盘价 < 黄金线 → 该周收盘离场。

## 四、运行

```bash
cd <技能目录>
python3 scripts/scan_inbull.py --months 3      # 扫描最近3个月的入牛事件
python3 scripts/scan_inbull.py --months 6      # 最近6个月
python3 scripts/scan_inbull.py --fetch         # 强制重新拉月线数据
```

- 数据源：同花顺 v6 line 接口（后复权）`http://d.10jqka.com.cn/v6/line/hs_{6位代码}/02/all.js`
- 月线缓存：`data/kline_month_adj.csv`（3 天内复用，避免每次重拉 15 分钟）
- 依赖 `data/all_mainboard.csv`（主板股票池 code,name）与 `data/pool.csv`（code,industry 行业分类）
- 输出：`outputs/入牛时点扫描_{YYYY-MM}.md`

## 五、回测结论（1990-12 ~ 2026-09，沪深主板 3,051 只，详见 references/method.md）

1. **「板块共振」是有效过滤**：板块未入牛的个股信号超额为负；板块已牛时个股跑赢所属行业 +4.66%（3 月）。
2. **「板块内率先入牛」没有优势**（12 月超额 −4.47%），**「板块入牛当月同步入牛」(Q1) 是最差时点**（12 月超额 −6.51%）。
3. **Q4（板块入牛 >6 月后个股才入牛）是唯一显著正超额**的分层；且**必须叠加「大盘牛市」**——Q4·大盘牛 12 月超额 **+9.31%**，Q4·大盘非牛仅 +2.29%。
4. **「创一年新高」有实质筛选价值**：取消后信号放大约 1.7 倍，超额反而变差，不建议取消。
5. **止盈口径**：周线破黄金线（+14.49%、胜率 61%）优于日线破线（+8.97%、胜率 66%）——日线更灵敏但收益更低；相对固定持有 12 月（+16.34%），该止盈**胜率与中位更优、均值与资金效率略低**，属偏保守型。

## 六、使用建议

- 优先关注 **大盘牛市 + 板块牛市 + Q4/Q3**（板块牛市运行 4 个月以上才入牛的个股）。
- **回避** Q1（板块刚入牛当月同步的个股）与「个股领先板块」的孤立信号。
- 买入后以**周线顶背离 + 破周线黄金线**作为离场信号。


## 八、短线/连板环境参考（2026-09 研究结论）

用于判断「现在适不适合做连板/妖股」，不替代上面的月线体系。

1. **连板"数量"强烈依赖行情，但"走远率"几乎不依赖。**
   - 数量：中期牛市月均 **60.4** 段 / 震荡 58.4 / 熊市 **31.0**（牛市月份占 47% 却贡献 56% 的连板段）
   - 走远率（连板≥5 占比）：短期 牛 23% / 震荡 22% / **熊 27%**；中期 牛 24% / 震荡 **19%** / **熊 27%** —— 22~27% 窄区间，熊市反而略高（能连板的都是极强势股）
2. **最该回避"中期震荡 + 短期震荡"的胶着期**（走远率仅 **14%**，n=257）。
3. **行业属性影响（23pct 跨度）远大于市场环境（3-8pct）。**
   走远率最高：纺织服饰 35%、轻工制造 35%、交通运输 34%、商贸零售 33%、社会服务 32%、国防军工 31%、家电 30%；
   最低：石油石化 12%、环保 13%、房地产/传媒 16%；科技大板块反而偏低：电子 24%、计算机 20%、电力设备 19%、基础化工 18%、有色 18%。
   → **"能不能走远"看行业与个股，"连板多不多"才看行情。**

**妖股启动画像**（前复权口径，1954 段/1227 只）：启动前已是强势股 —— 价 vs MA20 **+4.8%**、vs MA60 +9.8%、前20日 +10.5%、前60日 +18.0%、RS20 +8.0%、距60日高 85%、ATR20 4.7%、均线多头占比 **53.8%**（基准 31.6%）。
⚠️ 但该画像**无预测力**：同样特征的全样本（44,240 个）后续 20 日 **−0.89%**、胜率 40%。**特征是必要不充分条件**。

### 8.1 妖股「走得远」六维画像（70,452 个启动事件，2022-09~2026-09）

事件定义：当日涨 5%~25% + 量比≥2 + 前20日涨幅<25%。"走远" = 启动后 60 日内最大涨幅 ≥60%（**基准走远率 10.4%**）。

| 维度 | 结论 | 极值 |
|---|---|---|
| 外围市场 | **几乎无影响**，全区间 8.6%~10.7% 且不单调 | 纳指涨0~1% 10.7% |
| **板块环境** | **逆势**：行业越惨越好 | 行业60日<-15% → **15.9%**（中位+28.3%） |
| **启动方式** | 涨停 > 放量大阳 | 一字板 **13.3%** / 换手板 12.2% / **非涨停 9.2%** |
| **筹码** | **U 型**：深套或大幅获利都好，成本附近最差 | 低于60日成本>15% → **19.6%**；低于20日成本>10% → **29.0%** |
| **形态（建仓-拉升-洗盘-主升）** | ❌ **不成立**：两组前120日量价路径几乎重合（差<0.02） | 深跌<-25% 14.6% / 大涨>40% 13.8% / 横盘 9.7% |
| **资金** | 温和放量 > 爆量；**分水岭在启动后第3天** | 量比2~3倍 10.9% vs **8倍+ 8.0%** |

**最强单因子 = 波动率**：ATR20>6% → **19.5%**；ATR20<3% → **7.7%**。箱体>50% 13.7% vs 窄箱体<15% **6.5%**。

**两级漏斗（核心可操作规则）**：

| 层级 | 条件 | 样本 | 走远率 | 60日涨幅中位 |
|---|---|---|---|---|
| ① 事前 | 高波(ATR>4.5%) + 深跌(60日<-25%) | 1,955 | **20.8%** | +32.2% |
| ① 事前 | 高波 + 板块超跌(行业60日<-15%) | 1,502 | **21.1%** | — |
| ② +确认 | 上面任一 + **T+3 继续涨停** | 483 | **39.1%** | **+51.0%** |
| ② 对照 | 不加事前筛选 + T+3 涨停 | 7,481 | 30.7% | +43.0% |
| ② 淘汰 | T+3 转负 | 39,058 | **6.2%** | +10.8% |
| ❌ 反例 | 低波(ATR<3%) + 非涨停 + 爆量>5倍 | 1,444 | **6.4%** | +12.1% |

**启动后量能对比**（走远组 vs 未走远组，成交量/启动前20日均量）：T+1 3.80/3.81 → T+3 3.51/2.76 → T+10 3.95/1.93 → T+20 **4.01/1.67**。
**启动当天两组量能完全相同，从 T+3 开始分道扬镳。**

**一句话画像**：*高波动的小票，在跌透的行业里、深跌之后，用一个涨停启动；启动后第2~3天仍继续放量涨停 → 走远率约 39%（中位 +51%）。若 T+3 量缩价跌，93.8% 走不远。*

**三条硬规则**：① 事前只看波动率，不看形态；② 不信"建仓-拉升-洗盘-主升"形态学（无区分度）；③ 必须做 T+3 确认 + 止损 —— 这是**试错跟随**体系，不是预测体系（事前上限仅 21%）。

**三条硬结论**：
1. **弱市唯一稳定强有效的是「超跌反弹」**：中期熊市 S1(RSI<25) 20日 +10.26%（超额+22.68%、胜率63.2%）；短期熊市 +9.27%（+19.06%、68.5%）。

### 9.1b 盘前②.7 决策表口径（20年全历史 + 显著性检验 · 2026-09-14 最终版）

**判定规则（②.7 自动执行）**：两口径都正 → ✅主用（均值≥2% 且双双5%显著）/ 🟡可用（有1个显著正）/ ➖中性（正但不显著）；两口径都负 → ⛔关闭（有显著负）/ ➖中性（弱负）；一正一负 → ➖中性。

**审计结论（诚实版）**：
1. **只有 3 个信号通过显著性检验**：`S1超跌`（4/6 环境显著正）、`RSV启动`（3/6 环境显著正）、`猛兽·RS_D低吸`（1/6）。**其余全部不显著或显著为负。**

   **这不代表它们没用**——它们是"择时/结构确认"工具（判断"现在能不能买"），不是"选股 alpha 源"。若直接按信号无脑买入持 20 日，跑输等权基准 2~4 个百分点。
3. **⚠️ 日均口径 vs 事件加权口径会背离**（如 RSV启动 长期牛市：日均 +11.75% 但事件加权 −1.04%），说明信号在时间上高度聚集。**判显著性必须用日均口径**，事件加权会被少数暴涨日主导（旧版 S1 长期熊 +7.99% 就是被 2024-02 单一时段拉高的，日加权只有 +1.06%）。
