# 回测方法与本技能参数依据

**回测区间**：1990-12 ~ 2026-09（430 个月）
**样本**：沪深主板 3,051 只（剔除 ST/退市/科创/创业/北交所），32 个申万一级行业
**数据源**：同花顺 v6 line 后复权（adj=02）；月线由日线聚合，周线由日线按 ISO 周聚合

## 1. 信号与入场
- 信号 = 「5根月线全向上」由 非牛→牛 的**转折月**
- 入场 = 信号**次月开盘价**（避免未来函数）
- 基准 = 全市场等权持有同期收益

## 6. 已知局限
1. 幸存者偏差（仅当前上市股票）
2. 样本重叠（同一轮行情内信号高度相关，按月组合后 t 值仅 0.3–1.5，统计上不显著）
3. 行业指数为等权合成，与市值加权行业指数不完全等价
4. 未计交易成本、涨跌停无法成交
5. 月线级别下同月内的先后顺序无法区分（"率先"依赖 [d−6,d] 窗口近似）
