# 弱市体系复测（仓库真实脚本口径 × 市场环境分层）

**信号口径**严格照搬仓库脚本：`rsv_strength.py`（RSV均=(价格RSV+相对强度RSV)/2，N=144，基准=深证综指）/ `scan_123_2b.py`（123/2B法则）/ `wuwei_scan_month.py`（月线G1双阴·一阴缩量）。
**样本**：沪深主板 3,051 只 × 近 1,700 交易日（2021-01~2026-09，前复权），共 **2,411,403** 个信号观测。
**收益**：次日开盘买入，持有 5/10/20 日；**超额 = 个股20日收益 − 同期全市场等权20日收益**。
**环境**：短期=等权大盘 vs MA20/MA60（日线）；中期=大盘指数 vs MA6月/MA12月。

### 2. 三条可直接落地的结论

1. **弱市（熊市/震荡）里，唯一稳定强有效的是「超跌反弹」**：
   - 中期熊市：S1(RSI<25) 20日 **+10.26%**（超额 **+22.68%**，胜率 63.2%）
   - 短期熊市：S1 **+9.27%**（超额 +19.06%，胜率 68.5%）
   - 中期震荡：S1 +4.18%（超额 +10.31%）
2. **仓库里真正的「弱市工具」是 `rsv_strength.py` 的 RSV启动信号**（RSV均<20 且拐头向上）：
   短期熊市 +4.17%（超额 +9.86%，胜率 59.7%）、中期熊市 +2.50%（+6.00%）、中期震荡 +2.28%（+4.26%）。
   —— 它在四种弱市环境里**全部为正超额**，是体系内唯一做到的信号；但**牛市里彻底失效**（超额 -0.06%），属于纯逆势工具。
3. **必须按环境切换、不能全天候使用的**：
   - `武威G1·双阴` 是**顺周期**工具：牛市 +2.63%、短期熊市 +8.44% 有效，但**中期震荡 -0.63%、中期熊市 +0.68%（绝对收益 -3.44%、胜率仅 25.6%）** → 中期趋势走坏时必须关掉。
   - `123买入` / `RSV周线破50` 在所有环境超额 ≤0 → **建议从弱市工具里剔除**。
4. **`scan_123_2b.py` 的 2B 实现过于宽松**：25日窗口内「低点发生在3~20日前 + 现价高于低点2%」在全部观测中触发率 **86%**（2,132,333 次），几乎等价于「股价在近期低点上方」，没有筛选力（各环境超额 ≈0）。**建议收紧**：本报告额外测的「2B严格」（低点≥5日前形成 + 已收回5% + 站上MA5）触发率 38%，超额仍≈0 → 说明 **2B 法则本身在这套数据上不成立**。
