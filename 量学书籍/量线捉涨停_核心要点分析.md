## 〇、与《量柱擒涨停》的关系

| | 《量柱擒涨停》 | 《量线捉涨停》 |
|---|---|---|
| 研究对象 | 量柱（成交量柱） | 量线（关键价位连线） |
| 核心问题 | "是什么"（主力在做什么） | "为什么"（为什么到这就涨/跌） |
| 特点 | 量是"实"的，看得见摸得着 | 线是"脉"的，量价合一的参照系 |
| 定位 | 股市温度计 | **股市脉搏仪**（股票脉搏线） |
| 玩法 | 擒（拳脚相加、格物斗勇） | **捉**（游戏迷藏、捕捉，需动脑力） |

> 前言点睛："量柱是'实'的，量线是'虚'中见'实'"——量线只取K线中最有代表性的关键价位连线（开/收/高/低四价中选），是"量价合一"的参照系。

## 一、量线的基本原理（第一章）

### 三大特点
1. **前瞻性**（以点定线）：用"此前股价所处的位置"衡量"此后股价应有的位置"——从"为什么"入手解决"怎么办"；K线/均线只能解决"怎么办"（滞后性、经验性），量线解决"为什么"（前瞻性、主动性）
2. **度量性**（以线测点）：用"点"连线，反过来用"线"测"点"——数学可反证；精准线测出后"必然出现腾飞"
3. **互证性**（以线量线）：多条线互相验证，线与线的交叉/重合提供确认

### 三向规律（量线选点核心：极点、焦点、拐点）
- **极点测向律**：先找阶段高/低点（极点）画水平线——峰顶线、谷底线由此生成
- **焦点定向律**：找"同向同等"的价位重合点（焦点/要点）——精准线由此生成
- **拐点转向律**：拐点是趋势起点——**反向拐点**（回避阻力触顶回落/借助撑力触底回升）+**加速拐点**（反惯性思维甩掉技术派，"该跌不跌必然上涨，该涨不涨必然下跌"）

### 生成机制：七大元素（量线系统的"七根弦"）
| # | 元素 | 定义 | 角色 |
|---|---|---|---|
| 1 | **峰顶线** | 阶段最高点水平线 | 阻力线（群峰取2+峰顶画线价值最高） |
| 2 | **谷底线** | 阶段最低点水平线 | 支撑线（取最低点/实体低点/参照点，尽量找能形成精准线的点） |
| 3 | **峰谷线** | 峰顶线与谷底线顶底重合 | **唯一单向线**（只向上支撑），最少见但最具攻击力 |
| 4 | **趋势线** | 低点/高点连线成双轨 | 趋势通道线，上轨阻下轨撑 |
| 5 | **平衡线** | 多空力量对峙的水平线 | 阻力/支撑/另一轮行情的起跑线 |
| 6 | **精准线** | 2+个同向同等价位完全重合（±1分） | "擒庄绳"，庄家计划性的铁证 |
| 7 | **黄金线** | 攻击前回踩的起跳线/弹跳板 | 预示强力上攻行情 |

### 攻击体系（量线的实战应用层次）
- **双向异化**：平衡线双重性格——线上为支撑、线下为压力（动态变化，切合端点越多越可靠）
- **三级飞跃**：量线功能逐级升华
- **四步攻防**：取线 → 验线 → 用线 → 换线

## 二、七种量线详解（第二章·基本要素）

### ① 平衡线（多空共享的警戒线）
- 取点三原则：**实点平衡、整点平衡、密点平衡**
- 口诀：**"上行找实顶，下行找实底，实点靠整点，无点找密点"**
- 战术：反弹规划路线时先找上行平衡点

### ② 峰顶线（测顶攻顶的预警线）
- 不是简单"最高点画线"：孤峰 vs 群峰（群峰取2个以上峰顶，参考价值最高）
- 战略意义：测顶（见顶回落预警）；战术意义：攻顶（突破峰顶线=解放套牢盘→新目标）

### ③ 谷底线（探底与回升的生命线）
- 画法：以波段最低点画水平线，按股性调整为"实体低点"（收盘价）或"参照点"（左侧低点）
- 窍门：尽量寻找能形成"精准线"的最低点画线；多根谷底重合=强支撑

### ④ 峰谷线（顶底互换的进攻线）⭐
- 定义：峰顶与谷底自然重合（顶底互换）——"左峰成右底，众人持股成本抬高，新一轮攻击开始"
- **最少见但最具攻击力**：其所在涨幅是其他线段的两倍以上；狡猾的主力往往把它隐藏起来

### ⑤ 精准线（稀有且金贵的"擒庄绳"）⭐
- 定义：2个以上"同向且同等"价位重合（允许1分钱误差）
- 六大特性：**稀有性、计划性（庄家计划铁证）、爆发性、方向性、复合性、规律性**
- 实战："回踩精准线，起飞在眼前"——精准线当值记录在案，回踩确认即介入良机

### ⑥ 通道线（趋向与趋幅的回归线）
- 定义：趋势线+平行线=双轨线；股价到上轨向下回归、到下轨向上回归
- 分类：上升/下降通道、长期/短期通道、**太极通道/无极通道**

### ⑦ 灯塔线（太极与无极的导航线）
- 渊源：源自西山大师"佛光柱/佛光线"（周易八卦阴阳转换原理），易名"灯塔线"
- 功能：中长期导航，取点画线后几乎"十测九准"；有"有效射程"概念

## 三、实战技法精华（第三章战术 + 第四章实战）

**第三章·战术探讨（12-18讲）**：
- 找准一根线，涨停在眼前（专注一种线做到极致）
- 密集成交区找平衡线 / 抓住启动点短线好赚钱
- "大江有异常，必然要异动"（异常量=异动前兆）
- **阶段低量处藏有登山虎 / 百日低量柱筑底起宏图**（呼应量柱卷）
- 凹口抓涨停，关键在平衡

**第四章·实战技法（19-36讲）**：
- 凹口有横斜，闭眼抓斜勺 / 缩图看大势，放图找量柱
- 筑底平量柱，涨停三要素 / **守住黄金线，打劫是良机**
- **回踩黄金线，起跳在眼前** / 若现鹰嘴镐，可能创新高
- 预定黄金柱，提前测涨幅 / "U形量柱群"涨停三要素
- 介入宜提前，测幅宜保守 / 靠线蓄势股，逆势飞天虎
- 领悟灯塔线，精准每一天 / 找准平衡线，惊盘也悠闲
- **回踩精准线，起飞在眼前** / 看准大方向，破解回马枪
- 势变我亦变，一步一重天 / 触底欲起飞，看准第三位

**第五章·心术修养（37-41讲）**：重塑涨停观 / 知行合一 / 取法乎上

**第六章·切身体会（22则学员实战）**：核心口诀
- 倍量过左峰，涨停入囊中 / 凹口平量柱，确实猛如虎
- 预判黄金柱，实盘擒牛股 / 劫止黄金线，涨停任我捡
- 百日低量处，确实有卧虎 / 银谷黄金仓，涨停没商量
- 第二红波起，必然有好戏 / "凹底起柱""金谷起柱"涨停法
- 巧用峰顶线 / 顶底互换涨停法

## 四、可量化规则提炼（供量化体系借鉴）

| 量线规则 | 量化实现思路 | 与现有体系结合点 |
|---|---|---|
| 峰顶线=压力位 | 近N日最高价水平线，突破=攻顶信号 | 支撑/压力位标识、箱体突破 |
| 谷底线=支撑位 | 近N日最低价水平线，回踩不破=买点 | 均线回踩支撑体系 |
| **精准线**=2+同价位重合 | 检测近60日是否存在≥2个收盘/最低价差值≤1%的价位 | 独立信号源（庄家计划性） |
| 峰谷线=顶底互换 | 左峰价位被右底触及（峰→底转换） | 反转信号（与月线反转共振） |
| 平衡线=密集成交区 | 成交量密集的价格区间（筹码峰） | 筹码分析、成本线 |
| 百日低量柱=筑底 | 100日最低量后企稳 | 与低量柱/RSV低吸共振 |
| 回踩精准线/黄金线=买点 | 股价回踩前期精准线/黄金线不破 | 回踩买点信号源 |
| 凹口平量柱=蓄势爆发 | 凹口形态+平量柱组合 | 与箱体突破/鱼身信号结合 |

## 五、一句话总结

> **量柱问"是什么"，量线答"为什么"** —— 量线是量柱的"脉搏仪"：
> 七种线（峰顶/谷底/峰谷/趋势/平衡/精准/黄金 + 通道/灯塔）构成完整攻防体系，
> 核心执行逻辑：**画线定节奏（极点焦点拐点）→ 精准线验庄家计划 → 回踩不破=买点 → 突破峰顶线=攻顶**。
